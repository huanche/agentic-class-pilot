# 图片型 PPT 内容审核

PPTX 中的整页截图没有 DrawingML 文本。导入时，纯图片页会标记为待 OCR，
审核页自动请求原文件对应页面的识别结果；普通文本页继续使用本地解析。
高保真和 AI 增强共用此步骤，教师仍需确认内容和教学大纲。

- 服务端按 `presentation.xml` 的关系顺序读取原始图片，不改写上传文件。
- Qwen OCR 同时处理最多 3 页，60 秒超时；空结果、截断和上游错误不会标记完成。
- 结果按源文件 SHA、模型版本和页码缓存。MinIO 部署使用私有对象存储；
  本地模式使用课程数据目录下的 `pptx-ocr/`。重复进入无需重复调用已完成页面。
- 审核页支持原图核对、暂停、重试；刷新自动恢复未完成页，教师编辑不会被识别覆盖。
  保留的待识别页未完成前无法确认生成大纲。公式识别结果应结合原图审核。

默认模型 `qwen-vl-ocr`，使用阿里云兼容接口。
可选服务端配置：`PPTX_OCR_API_KEY`、`PPTX_OCR_BASE_URL`、`PPTX_OCR_MODEL`。
未设置专用密钥时，依次复用服务端 Qwen LLM、Qwen ASR、Qwen Image 的通用
DashScope 密钥；不会把密钥发给浏览器，也不需要开启云端 TTS。

本次没有数据库结构迁移。回退应用版本即可停用 OCR，已有缓存可以保留。
