同学们好，这一段我们学习 Python 变量与数据类型。请先观察左侧示例，name 等于小明，age 等于十八。变量可以理解为保存数据的名字，等号表示把右侧的值交给左侧变量。接下来比较右侧两个例子，整数十八可以直接参与加减运算，而带引号的十八是字符串。它们看起来相似，实际类型不同。我们可以使用 type 查看类型，也可以使用 int 把符合规则的数字字符串转换成整数。现在请暂停思考，如果先输入一个年龄，再加一，为什么可能报错？原因是 input 得到的是字符串，需要先完成类型转换。最后回顾，先看变量保存了什么，再判断数据类型，最后决定能进行哪一种运算。请结合屏幕上的示例，自己修改一个数值，并预测程序输出。
