## 本轮实现

### 版本与数据分离

平台和学生代码通过同一只读TCR产物交付，标签为`web-完整40位commit`，复用现有私有仓库，教师发布规则仍只接受main-七位标签。

版本目录：`/opt/agentic-mainland-web/releases/<sha>`；当前指针：`/opt/agentic-mainland-web/current`。两个服务的98-versioned-release.conf分别指向该版本。原/opt/agentic-class-pilot没有被reset或覆盖。

学生runtime仍指向/opt/agentic-class-pilot/student_agent/runtime；数据库、MinIO和教师数据保持原持久化路径。运行配置继续通过原环境文件注入，密钥不进入TCR产物或Git。

同一个版本在两个工作目录、健康检查都匹配时返回WEB_ALREADY_CURRENT。代码/配置切换失败会恢复原systemd drop-in和current指针，再启动旧版本。数据库revision与新源码heads不同会阻止上线，不自动执行不可逆数据迁移。

声明和锁文件完全相同时，复制已验证依赖环境到独立版本目录、调整editable路径并检查依赖一致性。声明变化时重新构建依赖环境；准备失败不会停止现有服务。本轮首次网络依赖下载慢，已终止准备并保留其目录为审计资料，未切换当时的服务。

### 网络与凭据修复

平台8080、学生8000均改为仅监听127.0.0.1；随后清除迁移期的出站阻断。学生AI原凭据可用。平台旧默认凭据返回401，已在大陆本机改用现有、经验证可用的同提供商凭据，并验证实际对话成功。香港及用户级模型配置未修改。

### 启动与恢复

新增agentic-mainland-start.service：先启动数据库/MinIO并等数据库就绪，启动内网转发及AI出口、语音服务、平台学生服务、教师容器及本地网关。Docker重启时也会执行该编排。

agentic-teacher-recover.timer每分钟检查异常退出的教师容器；和部署/备份共享锁。存在/etc/agentic-class-pilot/maintenance时不恢复，维护时应使用该标记及部署锁。

真实重启已完成。公网预览网关也已自启验证。请勿把删除开关文件当作停止在途部署；维护时先停止新发布，再确认互斥锁和运行状态。

## 正式切换方案（待用户允许修改香港生产入口）

1. 暂停两项大陆自动部署和定时备份，持有部署锁并设置维护标记；确认没有在途CI。把旧香港工作流的部署步骤加上开关并关闭，保留teacher构建以供大陆发布，不覆盖旧SSH Secrets。
2. 备份香港网关配置，启用已验证语法的维护页；等待教师任务结束，优雅停止香港平台、学生、教师和MinIO，保留PostgreSQL用于导出。
3. 停写后重新核对文件清单，导出最新education数据库和角色资料到大陆受保护目录。同步教师/runtime/MinIO差异，保留大陆当前完整备份；仅在大陆停止应用后恢复数据库。保留大陆端点和已修复的凭据配置，不把香港环境文件整份覆盖回来。
4. 验证数据库恢复、账号、已发布课程、对象存储、AI、三端页面和健康接口；失败时保持大陆入口受限，香港可以恢复原配置和服务。大陆未接受业务写入前，香港仍是回退依据。
5. 验证成功后，移除大陆预览来源限制，并把香港网关改为经TLS校验的大陆转发入口。香港原应用继续停用，只有大陆后端可写；缓存旧DNS的客户端也经香港转发到大陆。
6. DNSPod中将agenticclasspilot.com的现有A记录从43.132.155.8改为43.138.178.158，TTL可设300。当前没有本机DNSPod API连接，这一步需要用户在控制台执行；不需要把密钥发到聊天。核对是否有多线路或AAAA记录，避免遗漏。
7. 复查新旧入口实际后端一致、HTTPS和业务流程，恢复大陆发布和备份；观察后再决定香港下线时间。若大陆已经有新写入，回退必须先处理这些增量，不能仅切回DNS。
