# 配音前讲稿预算与片段校时试验

本功能先在本地按同一份 PPT、每轮最多五页进行对照验证。保留原模型、正常播放语速、独立讲稿/聚焦检查、真实音频测时和现有最终时长容差。

## 开关与范围

`COURSEWARE_NARRATION_BUDGET_ENABLED=true` 启用后台生成试验路径；默认关闭，现有部署行为不变。关闭开关可恢复原来的整页讲稿校时路径。

试验路径用于后台课件任务。幻灯片可以做局部讲稿修订；互动页沿用原有动作生成与校时逻辑，并可使用同一任务已观测到的音色速度作为首稿参考。测验与 PBL 不纳入自动讲解时长目标。答题仍为每题五分钟。

## 执行流程

1. 没有本次音色观测值时，从第一张适用幻灯片中选取最多两段真实、完整的讲稿进行配音抽样。使用同一音色、模型和语速，音频进入原有精确缓存；抽样临时文件随后清理。
2. 按本任务真实音频持续学习朗读速度。观测按完整 TTS 配置身份隔离，身份包含音色、模型、语言、凭据哈希和其他影响音频的参数；身份变化时丢弃旧观测。只学习正常语速、可测量的音频，不把估计值保存为实测值。
3. 已有观测值时，首稿提示包含可朗读长度预算。汉字、英文字符、数字和标点采用不同权重，避免把代码字符串长度直接当成中文朗读字数。
4. 整页配音前，估计偏差超过页面预算的 12% 时进行一次有界的局部修订。程序选择少量具有明确聚焦目标的教学段落，模型只能返回这些段落的替换文字。开场、过渡和其他正文保持原文，画布、动作顺序、聚焦目标、揭示动作和播放语速保持原值。
5. 程序检查替换范围、长度是否向目标收敛以及替换长度是否进入允许范围。之后独立语义检查覆盖最终完整页面的每一段，不能只审查被修改的段落。
6. 未改的文本从现有精确音频缓存复用。修改文字的配音重新生成。候选使用独立的音频标识，避免保存失败后的清理删除上一版课件声音。
7. 最终仍按可解码音频的真实时长测量。原来的页面与整课 ±5% 判断、有界修正次数和保留最佳可播放候选的逻辑不变。实际配音后的幻灯片校时同样优先使用局部文字修订；原样片段继续命中缓存。

12% 是配音前估算的筛选阈值，不是对最终真实播放容差的放宽。估计时长不能写入 `measuredDurationSec` 或伪造测量指纹。

## 质量与回退

- 修订失败或语义检查不通过时，不能替换已审查的原稿。配音前保留原稿进入真实配音和既有校时；配音后的修订失败由既有最佳候选策略保留可播放版本。
- 服务错误、取消和配音失败按既有规则传播，不能用静音或伪造音频兜底。
- 未改正文的音频复用要求文字及完整 TTS 配置相同，不能把旧音频挂在已经修改的讲稿上。
- 视频等无法由现有测量器完整测量的时间轴，不使用该估算来宣称时长达标。
- 语速观测仅存在于本次任务，尚不跨任务持久化。不能把某个音色在某份材料上的速率当作所有语言、音色的固定常数。

## 验证

自动化检查覆盖局部替换范围、正文与聚焦动作保留、整页独立语义检查、测量失效、音色观测隔离、未知时间轴、取消、被拒修订、未改录音字节一致性及候选回退后的旧音频可读性。

本地对照采用两页幻灯片、互动、测验和 PBL 各一页，目标自动讲解三分钟。两轮使用同一 PPT 内容、大纲、模型、音色和时长设置；均为空音频缓存起步，串行运行，避免 TTS 资源争用。对比总耗时、首个完整页耗时、实际音频完整性、真实播放时长、模型调用、TTS 合成请求及缓存复用；人工检查公式、代码、可见知识点和讲稿聚焦。

测试记录保存在 `teacher_agent/.runtime/narration-budget-20261021/`，包含实际讲稿与上传材料衍生文本，保持在本地，不作为公开提交内容。

## 2026-10-21 本地对照结果

同一份 CH2 PPT、同一组五页大纲（幻灯片两页、互动、测验、PBL 各一页），两轮均使用 DeepSeek V4 Flash 和本地 CPU Kokoro / zf_xiaoyi，正常语速、各自空缓存起步。统计从已确认大纲开始，不包含共同的上传、OCR 和大纲生成时间。

| 指标 | 原流水线 | 配音前预算与局部修订 |
| --- | ---: | ---: |
| 五页生成总耗时 | 15:52.328 | 8:32.780 |
| 首个完整页可用 | 5:37.696 | 4:27.344 |
| 实际 TTS 合成请求 | 61 | 23 |
| 配音缓存命中 | 0 | 2（复用抽样讲稿） |
| 动作/讲稿接口调用 | 14 | 7 |
| 配音后页面校时次数 | 6 | 0 |
| 三页自动讲解实际总时长 / 目标 | 3:01.847 / 3:00 | 2:57.690 / 3:00 |

本次总耗时减少 46.16%，TTS 合成请求减少 62.30%。优化后三页自动讲解分别为 60.471、57.271、59.949 秒，均在原 ±5% 容差内。五页共 23 段最终音频，全部实际解码、PCM 非静音；最终讲稿与聚焦结构检查通过，已观测音频时长的测量指纹一致。

这是单次配对试验，模型输出存在波动。画面生成的累计接口耗时反而从 4:41.495 增至 5:46.588；提速主要来自减少讲稿校时和重复 TTS，不能据此承诺十五页的固定完成时间。优化后实际 TTS 请求累计仍耗时 4:41.125，是剩余主要成本之一；累计阶段时长存在重叠，不应直接相加当作总耗时。

### 内容审查与独立修订记录

原始自动生成样本不能直接宣称内容质量全部通过。人工审查发现，画面首稿已经把“单次幅度谱”和“周期图”的表述混在一起，并缺少宽平稳、遍历性条件；采样页还需区分数学编号 n=39 与 MATLAB 数组 t(40)。配音预算修订没有修改这些画布首稿。周期图用于估计功率谱密度，可对照 [SciPy 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)；相关理论范围可对照 [MIT 功率谱密度教材](https://ocw.mit.edu/courses/6-011-introduction-to-communication-control-and-signal-processing-spring-2010/resources/mit6_011s10_chap10/)。

保留原始对照产物不变，另建本地审查副本修订四段讲稿及对应可见文本。独立整页聚焦检查曾拒绝一段跨区解释，之后按原校验要求修订；第一次音频复核有一页超出单页容差 0.259 秒，进一步删除冗余措辞后通过。额外机器处理约 1:56（含被拒检查、首次修订和最终复核，不含人工审读时间），没有混入上表提速数据。

最终审查副本的三页自动讲解分别为 61.217、61.446、59.949 秒，总计 3:02.612，全部保持原 ±5% 容差；未改讲稿的音频字节校验一致，23 段均有真实声音。人工内容审查仍是必要步骤；本试验没有新增全面的事实正确性验证器。

相关自动化回归为 10 个文件、93 项检查通过，修改范围的严格 TypeScript 检查和 ESLint 通过。全项目 TypeScript 检查因本机堆内存不足未完成，不能据此宣称全仓检查通过。浏览器验证覆盖翻页、互动欠采样参数变化、测验提交及项目页显示。

代码默认关闭。生产部署需在服务器环境中显式设置 `COURSEWARE_NARRATION_BUDGET_ENABLED=true`，并重新创建教师端容器；普通容器 restart 不会重新读取 env-file。回退时将该开关设为 `false` 并重新创建容器，原有整页校时路径仍可使用。配置切换前保留环境文件备份，并等待正在生成的任务结束。
