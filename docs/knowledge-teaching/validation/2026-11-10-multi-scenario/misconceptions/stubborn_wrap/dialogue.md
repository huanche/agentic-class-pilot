## 导师开场

我们先看顺序队列的一个现象：假设数组容量为 8，front = 3、rear = 8，此时 0~2 号位置其实还空着，但再入队却会报溢出。请你说说，这种情况为什么叫“假溢出”？循环队列又是怎样解决它的？

## 第1次：循环队列与假溢出的解决 / recall

**学生**

我觉得 rear 到 8 就该绕回 0 吧，0~2 明明空着，为什么不能接着入队呢？可我又有点糊涂，普通队列是不是本来就不会自动绕回去？

**导师**

你问到了关键处：普通顺序队列确实不会自动绕回。它的入队只做 rear = rear + 1，rear 到 8 就超出数组末端，程序便报溢出；可 0~2 号位置还空着，所以这种“溢出”是假的，空位并没有真正用完。循环队列的做法是把数组首尾接成一个环，用取余让指针绕回：容量为 8 时，rear = 8 的下一次入队位置是 (8 + 1) % 8，也就是 0 号位置。请你先算出这个位置，再用自己的话说说：为什么取余能让 rear 从末端回到开头？

## 第2次：循环队列与假溢出的解决 / recall

**学生**

(8 + 1) % 8 算出来是 1 吧？不对，我老觉得 8 后面就是 0，所以可能是 0。取余是不是因为到 8 就整除完了，剩下的就回到开头？

**导师**

你这次算对了：(8+1)%8 的结果是 1，不是 0。这里要分清两件事：rear=8 本身已经越界了，8 号位置并不存在；取余算的是“下一次入队该放在哪”，9÷8 商 1 余 1，所以下一次位置是 1。你说的“到 8 就整除完”不准确，因为 9 除以 8 并没有整除，余数是 1。

再看假溢出的成因：普通顺序队列里 rear 只会加一，不会绕回，所以 rear 到 8 就报溢出，0~2 的空位根本用不上。循环队列用取余让 rear 绕回，就能接着用这些空位。

现在请你用自己的话把这条因果链说一遍：普通队列的 rear 只加一、不绕回 → 前端空位用不上 → 假溢出；循环队列用取余绕回 → 空位能复用。
