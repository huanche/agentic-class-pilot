# 高保真 PPTX 动画与讲解聚焦

高保真导入会保留支持的原生进入/退出动画、点击分组、先后顺序、延迟、时长、段落构建和形状背景构建。浏览器播放支持 appear、fade、fly、wipe、zoom、box(out) 及淡入淡出页面切换；暂停、继续、重播、跳转和播放倍速共用播放时钟。

高级运动路径、强调效果、交互触发器、重复动画等尚未完整支持。导入内容确认页会展示兼容提示；不支持的对象保持可见。视频导出不包含本次浏览器原生动画播放能力。旧版 `.PPT` 仍需转换为 `.PPTX`，没有增加服务端自动转换。

讲解生成器会读取文本框、形状内的文字和代码、表格、公式及位置，为聚焦动作选择实际教学区域。不存在的目标编号会跳过，不再替换为页面的第一个元素；兜底整页讲解也不猜测目标。讲解应逐段对应一个区域，比较多个区域时分别聚焦，不把空白代码骨架描述为完整实现。单页讲解重生成会保留并重新绑定原稿动画。

此次修改适用于新导入/生成的课程。已有课件不会自动补入原生动画或改写讲解，需要重新导入/生成；普通讲解重生成只能保留该页已经存有的原生动画数据。

本地使用用户提供的 `Lec 6_1.PPT` 转换样本，实际生成 3 页原稿幻灯片、1 页互动和1页测验，沿用 DeepSeek v4 Flash 与 Kokoro。首轮生成约 3 分 46 秒，随后根据实测问题修订第一页；最终 30 个聚焦片段复查未发现错位，37 段配音通过文件、非静音和访问校验。该结果是样本验证，不是任意 PPT 的准确率保证。
