# Feature Specification: 更换"加入课程"页面视觉

**Feature Branch**: `001-join-course-page`

**Created**: 2026-10-09

**Status**: Draft

**Input**: User description: "加入课程应该不是这个页面,有另外一个好看的页面,你帮我查找一下然后更换当前页面"

**背景(调研结论)**: 当前平台侧栏"加入课程"进入的是一个朴素的单卡片表单页;而学生学习空间(学生 Agent)内已存在一套精致的全屏选课页——全屏柔和背景遮罩、居中窄卡片、顶部图标徽章、标题+引导文案、精心排版的课程码输入框。本功能将平台"加入课程"页面更换为该套视觉体验。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 全屏选课页替换现有表单页 (Priority: P1)

学生从平台侧栏点击"加入课程"(或首页的"使用选课码加入课程"按钮),看到的不再是嵌在布局里的小表单卡片,而是一个沉浸式全屏页面:柔和的背景遮罩、居中的窄卡片、顶部图标徽章、"加入课程"标题与"输入教师分享的 8 位选课码"引导文案。学生输入选课码提交后,看到包含课程名的成功提示,并自动进入该课程页面。

**Why this priority**: 这是本功能的全部核心价值——用已验证的精致视觉替换朴素表单,同时保持选课能力不变。仅完成此故事即可交付完整价值。

**Independent Test**: 用任一学生账号从 8088 入口进入平台,点侧栏"加入课程",核对页面呈现为新全屏设计;用有效选课码完成加入,确认成功提示与跳转行为与更换前一致。

**Acceptance Scenarios**:

1. **Given** 学生已登录平台, **When** 点击侧栏"加入课程", **Then** 进入全屏选课页,视觉与学生学习空间的选课/登录页同一语言(遮罩背景+居中卡片+图标徽章+标题副标题)
2. **Given** 学生在全屏选课页输入有效 8 位选课码, **When** 提交, **Then** 看到成功提示(含课程名)并自动跳转到该课程页面
3. **Given** 学生已在课程中, **When** 再次访问"加入课程"页面, **Then** 页面正常呈现,可继续为其他课程输入选课码

---

### User Story 2 - 输入与反馈体验 (Priority: P2)

学生在新页面输入课程码时获得与学生学习空间一致的细节体验:输入自动转大写、等宽字体宽字距展示、无码时页面提供"找任课老师要"的引导文案;提交过程中按钮呈进行中状态且不可重复点击;无效码失败后已输入内容保留、焦点回到输入框。

**Why this priority**: 决定"好看"之外"好用"的部分,保证视觉升级不牺牲可用性;依赖故事 1 的页面存在。

**Independent Test**: 依次输入小写字母、错误码、连点提交按钮,核对大写化、错误提示、防重复提交与焦点行为。

**Acceptance Scenarios**:

1. **Given** 学生在选课码输入框键入小写字母, **When** 继续, **Then** 显示内容自动为大写、等宽、宽字距
2. **Given** 学生输入无效/过期选课码, **When** 提交, **Then** 显示友好中文错误提示,输入内容保留且焦点回到输入框
3. **Given** 提交请求进行中, **When** 学生再次点击提交, **Then** 不产生重复请求,按钮呈进行中状态
4. **Given** 学生尚无选课码, **When** 停留在页面, **Then** 可看到"还没有课程码?找任课老师要一个"类引导文案

---

### User Story 3 - 入口与行为一致性回归 (Priority: P3)

平台所有指向"加入课程"的入口(侧栏项、首页按钮、学生首页/我的课程空状态提示)均进入新页面;加入成功后"我的课程"数据即时刷新;学生学习空间(学生 Agent)内部现有的选课页不受影响。

**Why this priority**: 保证更换不产生入口不一致与回归,是收尾性质的质量保障;依赖故事 1。

**Independent Test**: 逐一访问侧栏、首页按钮、空状态提示入口,确认都到达新页面;加入课程后回看"我的课程"列表即时包含新课程。

**Acceptance Scenarios**:

1. **Given** 平台任意页面, **When** 经侧栏或首页按钮进入"加入课程", **Then** 均呈现新全屏页面
2. **Given** 学生通过新页面成功加入课程, **When** 返回"我的课程"/学生首页, **Then** 新课程即时可见,无需手动刷新
3. **Given** 学生从已加入课程进入学习空间, **When** 学习空间内触发选课(无课门面), **Then** 学生 Agent 内现有选课页保持原样、不受本次更换影响

---

### Edge Cases

- 选课码含前后空格或小写 → 提交前自动去除空格并统一大写
- 同一学生对同一课程重复加入 → 沿用现有后端判定,页面给出明确中文反馈,不出现静默失败
- 网络请求失败/超时 → 显示可重试的友好错误,不丢失已输入内容
- 学生长时间停留在页面后会话过期 → 沿用平台现有登录态处理,不出现样式错乱

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 平台"加入课程"页面 MUST 更换为沉浸式全屏设计,视觉基准为学生学习空间(学生 Agent)内现有选课页:全屏柔和遮罩背景、居中窄卡片、顶部图标徽章、标题与引导副标题(已确认,Q1=A,2026-10-09)
- **FR-002**: 选课码输入 MUST 自动大写展示,采用等宽字体、宽字距,长度上限 8 位
- **FR-003**: 提交 MUST 校验非空;无效码 MUST 展示友好中文错误,保留输入内容并将焦点返回输入框
- **FR-004**: 提交进行中 MUST 呈进行中状态并阻止重复提交
- **FR-005**: 加入成功 MUST 展示含课程名的成功反馈,并保持现有跳转行为(进入对应课程页)与"我的课程"数据即时刷新
- **FR-006**: 现有选课能力与规则(8 位选课码、后端校验、重复加入判定)MUST 保持不变;本功能仅更换平台前端页面呈现
- **FR-007**: 平台全部"加入课程"入口(侧栏、首页按钮、空状态提示)MUST 进入新页面;路由地址保持不变
- **FR-008**: 学生学习空间(学生 Agent)内部的选课页 MUST 不受本次更换影响

### Key Entities *(include if feature involves data)*

- **选课码 (Enrollment Code)**: 教师创建课程时生成的 8 位标识,学生凭此加入课程;属性:8 位、大小写不敏感(输入侧统一大写)
- **选课记录 (Enrollment)**: 学生与课程的关联;本功能不改变其数据结构与创建规则

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 持有有效选课码的学生,从点击"加入课程"到完成加入并进入课程页,可在 30 秒内完成
- **SC-002**: 新页面与学生学习空间选课/登录页视觉语言一致(同遮罩、同卡片结构、同图标徽章布局),团队走查验收通过
- **SC-003**: 成功与失败路径 100% 有明确用户可见反馈,无静默失败场景
- **SC-004**: 选课核心能力回归零缺陷(有效码加入、无效码提示、重复加入反馈、跳转与列表刷新均不劣化)

## Assumptions

- 视觉基准已确认(2026-10-09,Q1=A):学生学习空间(学生 Agent)的现有选课页设计(全屏遮罩+居中卡片+图标徽章)
- 仅更换平台前端的页面呈现;选课逻辑、后端接口、选课码规则均不变
- 路由 `/join` 与各入口地址保持不变,不新增路由
- 视觉借鉴仅复制样式语言,不跨服务引用学生 Agent 的代码(符合宪法第 I 条服务边界自治)
- 移动端深度适配不在本期范围(平台当前桌面优先)
- 学生 Agent 内部选课页保持现状,不纳入本次改动
