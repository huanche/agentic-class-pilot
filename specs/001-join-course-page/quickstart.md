# Quickstart: 验证"加入课程"页面更换

**Date**: 2026-10-09

## 前置条件

1. 本地全栈环境已启动,从 `http://localhost:8088` 进入(参考 platform/LOCAL-RUN.md)
2. 一个**学生**测试账号(见 `platform/LOCAL-ACCESS.txt` 或测试配置)
3. 一门已建课程的**有效 8 位选课码**(教师侧获取);另备一个无效码(如 `AAAAAAAA`)

## 人工走查(对应 spec 验收场景)

1. **入口与视觉(US1-1)**:学生登录 → 点侧栏"加入课程" → 应呈现全屏柔光背景 + 居中玻璃卡片 + 图标徽章,与学生学习空间选课页同视觉语言;侧栏被覆盖
2. **成功路径(US1-2)**:输入有效选课码 → 成功提示含课程名 → 自动跳转该课程页
3. **重复进入(US1-3)**:再次进入 `/join` → 页面正常,可继续输码
4. **输入体验(US2-1)**:输入小写字母 → 自动显示为大写等宽宽字距
5. **失败路径(US2-2)**:输入无效码提交 → 卡片内中文错误;输入值保留;焦点在输入框
6. **防重复(US2-3)**:连点提交 → 只有一个请求,按钮呈进行中
7. **引导(US2-4)**:页面可见"还没有选课码?找任课老师要一个"
8. **一致性(US3-1/2)**:从首页按钮进入也是新页面;加入成功后回"我的课程",新课程即时可见
9. **学生端不受影响(US3-3)**:进入学习空间触发选课门面 → 仍是学生端原页面
