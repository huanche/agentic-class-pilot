# Data Model: 更换"加入课程"页面视觉

**Date**: 2026-10-09

## 结论:无数据模型变更

本特性为平台前端呈现层重写,**不新增、不修改任何数据实体与接口**。以下既有实体只读使用:

- **选课码 (Enrollment Code)**:8 位标识,教师创建课程时生成;输入侧统一大写、去空格、上限 8 位。生成与校验规则均不变。
- **选课记录 (Enrollment)**:学生与课程的关联,由既有 `enrollments` 接口创建;结构与判定(重复加入等)不变。

## 前端呈现层校验(非数据变更)

沿用现有 zod schema 规则(非空、最小长度、maxLength 8),仅呈现方式变化;后端校验是唯一事实源,前端校验仅为即时反馈。
