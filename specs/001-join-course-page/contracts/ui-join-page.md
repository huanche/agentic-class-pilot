# UI Contract: 平台"加入课程"页(更换后)

**Date**: 2026-10-09 | 对应 spec: FR-001~FR-008

> 本特性无 API 契约变更(复用既有 enrollments 接口);以下为页面行为契约。

## 入口契约(不变)

| 入口 | 行为 |
|---|---|
| 侧栏"加入课程" | 打开 `/join` |
| 首页"使用选课码加入课程"按钮 | 打开 `/join` |
| 学生首页 / 我的课程空状态文案 | 指引到"加入课程"(措辞不变) |

## 页面呈现契约(新)

- 全屏沉浸覆盖层:覆盖整个视口(含侧栏),柔光渐变背景,居中 380px 玻璃质感卡片
- 卡片内容自上而下:学位帽图标徽章 → 标题"加入课程" → 副标题"输入教师分享的 8 位选课码" → 选课码输入框 → 提交按钮 → 引导文案"还没有选课码?找任课老师要一个"
- 输入框:自动大写、等宽、宽字距,上限 8 位
- 进入页面时输入框自动聚焦;卡片有一次性入场动画(约 0.5s),不阻塞交互

## 交互契约

| 场景 | 行为 |
|---|---|
| 空码提交 | 前端拦截,不发起请求,提示需输入 |
| 无效/过期码 | 卡片内内联中文错误;输入值保留;焦点回输入框;按钮恢复可点 |
| 提交进行中 | 按钮 loading 态;重复点击不产生重复请求 |
| 加入成功 | 成功反馈(含课程名);自动跳转该课程页;"我的课程"数据即时刷新 |
| 网络失败 | 可重试的友好中文错误,不丢输入 |
| 会话过期 | 沿用平台既有登录态处理 |

## 不变式

- 路由地址 `/join` 不变;不新增路由
- 后端接口、选课码规则、重复加入判定不变
- 学生学习空间(学生 Agent)内部选课页不受影响
