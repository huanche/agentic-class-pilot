## 2. 颜色系统（4 brand hex + 2 中性）

| 角色 | hex | 用途 |
| --- | --- | --- |
| 主色 | `#1B4F9C` | 标题竖条、章节大字、表头、时间轴主线、节点主框 |
| 辅色 | `#3D7BE0` | 次级节点框、图表第二系列、进度辅助 |
| 浅底 | `#E8F0FB` | 卡片底、表格斑马纹、区块衬底 |
| 强调 | `#F59E0B` | 巨型数字、关键结论、"切幕/证据"焦点标注（≤10%） |
| 中性·深 | `#0F2E5C` | 标题与正文深色文字 |
| 中性·灰 | `#64748B` | 副题、页脚、辅助说明 |

**面积分配**：内容页 白底为主，浅底卡片 ≤30%，主色 ≤15%，强调 ≤5%；Hero 页（01/04/11/18）主色面积可至 35-60%，强调可至 15%。
**渐变**：仅封面与章节扉页允许 `linear-gradient(135deg, #1B4F9C, #0F2E5C)` 作左侧色带；内容页一律纯色。

## 4. 密度与留白

- 内容页正文 ≥180 字或表格 ≥5 行；卡片填充率 ≥85%，尾部元素用 marginTop:'auto' 钉底。
- 常规内容页留白 ≤35%；扉页 / 封面 / 结束页留白可达 45%（声明为留白型）。
- 每页 ≥1 个视觉锚点（≥44px 元素或 ≥40% B 区主视觉）。

## 5. 配图分级

本 deck 为技术架构介绍，**主视觉全部为结构化 SVG**（流程图、时间轴、目录树、两层结构图、几何线框），不使用摄影/插画——已在 STORY 声明为"抽象几何/结构化概念页"豁免。L3 角标：页脚左侧小方块徽标（10×10 主色方块 + 文字），全篇位置一致。
