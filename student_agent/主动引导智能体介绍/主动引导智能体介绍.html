逐幕体验：学生做什么、AI 做什么、星级怎么变

星级只升不降 · 5 星只能由正式考核给出 · 学生说「我懂了」不是证据
幕学生经历什么AI 在做什么掌握星级变化
开场 intro收到本课目标与互动方式说明系统幕：交代规则，一轮后立即切幕—
引导学习听讲解、被主动提问，按片段（segment）逐段推进按 segments/seg-XXX.json 逐段讲解，讲完即记「已接触」0 → 1 星（AI 讲过即记，不讲不记）
复述与讨论用自己的话把刚讲的内容讲回来从题库抽检验问题追问 1–2 轮，按完整度判星、补缺口1 → 2 星（零散要点）→ 3 星（完整讲回）
深层探究回答「为什么 / 如何实现 / 用在哪 / 关联学科」拿 KNOWLEDGE-BASE 的 4 个探究字段追问；没答透的旧目标优先补问3 → 4 星（说出机制原因；只说结论维持 3 星）
全班讨论转入老师主导的课堂讨论退居协助：提示「请老师主导」+ 计时，到点切幕星级不变，只记综合表现快照
收尾 ending收到总结与遗留问题清单系统幕：汇总本课，列出未关闭目标—（考核入口独立给 5 星）
每幕结束拍一张快照（stage_snapshot 写入 mastery-history.json）：记本幕耗时、关闭了哪些目标、还剩哪些 —— 老师看到的是学生「一步步怎么变的」，不只是一个最终分数。

02
老师端 · 课前配置
老师不用写提示词、不用懂状态机。开课前只做两件事：定阶段与时长，填课程内容文件。规则与配置就是燃料。

第一步：lesson-plan.json 定阶段与时长

lesson-data/lesson-plan.json —— 编排入口，load_plan 节点开课时读取并校验
{ "lesson_id": "ch3-process-scheduling", "total_minutes": 45, "stages": [ { "id": "guided_learning", "enabled": true, "minutes": 22, "advance_when": "either" }, { "id": "recap_discussion", "enabled": true, "minutes": 9, "advance_when": "either" }, { "id": "deep_inquiry", "enabled": true, "minutes": 7, "advance_when": "either" }, { "id": "class_discussion", "enabled": false, "minutes": 7, "advance_when": "budget" } ], "advance_policy": { "on_budget_exhausted": "wrap_up", // 到点:收尾后切 "on_evidence_reached": "advance", // 证据达标:切幕 "min_stage_minutes": 2, // 防秒切 "max_stage_overrun_minutes": 3 // 延长上限 } }
字段含义
enabledfalse 整段跳过，这门课可以不要讨论
minutes这一幕的时长预算，真实时钟到点切幕
advance_wheneither 证据或时间先到先切 · evidence 学透才走 · budget 只看时间
改 JSON 就是改课。加一幕、砍一幕、调整分钟数，都不用碰任何代码与提示词 —— 状态机每轮读这张表。

五类内容文件，各自的用途与被编排器读取的时机
文件老师写什么编排器何时 / 被谁读取
rules/KNOWLEDGE-BASE.md知识点目录：定义、检测问题、掌握表现 + 4 个探究字段（为什么/如何/用在哪/关联学科）每轮由 load_context 装配；探究字段是深层探究阶段的唯一燃料；检测问题是复述题库的最后一级兜底

runtime/LESSON-CONTENT.md本课先修 / 新内容 / 任务 / 成功证据讲解阶段装配，决定「这一段要讲到什么程度」
lesson-data/segments/seg-XXX.json每个片段讲什么，order 定顺序，绑定 KP 编号引导学习阶段逐段驱动：active_segment_id 指向哪段就讲哪段

提问三级兜底链：stages/*/questions.md（老师出题）→ 空则用 TMISSION.md 检验问题 → 再空则用 KNOWLEDGE-BASE.md 检测问题。空壳也保证有题可问。

teach 两层铁律：模型只管措辞，不管编排

实测踩出来的架构铁律 —— 最初「有 LLM 就调模型」导致段落不推进、编排被架空
三条约束（每条都是踩坑踩出来的）原因
directive 必须带内容锚点只写「往深讲一层」→ 模型编出本课没有的「马尔可夫性质」（幻觉）
给模型的文案不能含 KP 编号模型会照着念「KP-004」→ 用 kp_title() 转中文标题
收尾轮 directive 显式禁止新内容否则模型在「总结一下」里继续往外扩
51 / 51
有 / 无 LLM 跑同一串时间戳，剔除回复文本后，编排结果逐行相同 —— 切幕、星级、推进不受模型影响，已被验证。

真实时钟 tick 与切幕判定 judge_advance

时钟只算已花时长 —— 编排器绝不判断学生是否缺席，那是在场性归老师管
tick：全图唯一读时间的地方
def tick(state): now = fromisoformat(state["now"]) # 外部注入 return { # 本幕已花 = now - 本幕开始 "stage_elapsed_minutes": ..., # 本课已花 = now - 开课时刻 "lesson_elapsed_minutes": ..., }
时间做成输入而非节点自取 → 图是纯函数：可单测、可回放。tick 同时是每轮复位点，清掉上轮证据与判决，防止跨轮渗漏。
judge_advance：短路判定，命中即停（每轮执行）
1
本幕演够 min_stage_minutes（2 分钟）了吗？没够 → 留幕（防秒切）
2
「学透才走」模式且还有目标没关闭？→ 留幕（证据优先于时间）
3
证据齐了、目标全关闭？→ 切幕（学得快就提前走）
4
到时间预算了？看策略：force_advance 立即切 / wrap_up 收尾后切 / extend 允许延长 ≤3 分钟 → 多数切幕
5
以上都没命中 → 留幕，等下一轮再判。判决理由写 advance_reason 落盘，老师可复盘「为什么在 22 分钟切了」
