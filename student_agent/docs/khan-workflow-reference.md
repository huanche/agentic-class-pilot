# Khan Academy / Khanmigo 学习流程核查

核查日期：2026-10-26。仅使用官方全文，区分原生产品流程与本项目适配建议。未登录实际学生账户，以下为官方使用说明和产品测试报告可证实的行为。

## 原生流程：技能练习、求助与再次检验

Khan Academy 不是一个固定的“看完整段视频后统一初诊”的产品。以官方 SAT 课程为例，学生可以先用 Course Challenge 找出需关注的技能，也可以直接学习技能相关课程和视频，再进行 Foundations、Medium、Advanced 的分级练习；短测和单元测试用于检查进展。视频通常是短例题讲解，不应描述成我们现有的整段课堂播放。[S1]

```text
选择技能，或用 Course Challenge 定位需要关注的技能
    → 学习相关课程／视频，进行技能练习
    → 困难时就当前问题获得 Khanmigo 辅导
    → 继续解题和练习
    → 测验／单元测试／课程挑战提供后续表现
    → 技能状态更新，查看结果和推荐课程，再学习
```

这是对官方组件关系的归纳，不表示系统要求学生按此顺序完成每个步骤。官方明确支持的关键关系是：

- **辅导围绕当前练习题。**学生在练习中打开 Khanmigo 时，辅导器能看到当前题目。官方产品测试进一步接入近期正误记录、技能水平和未掌握先修技能。[S3]
- **辅导依赖可核查的教学资源。**其数学辅导会获取人工制作的习题、步骤、提示和解答，也针对图形提供文字表示，并配合数学校验工具。不能据此推断它只是把课件交给通用聊天模型。[S4]
- **学习状态来自后续作答。**练习、短测、单元测试和课程挑战都能影响技能状态。活动结束显示哪些技能上升、下降或未变，并可能推荐课程。技能状态包括 Not started、Attempted、Familiar、Proficient、Mastered。[S2]
- **辅导质量检查“下一题能否独立做”。**其 2026 年产品实验采用同次会话、同技能的下一题、没有 Khanmigo 帮助时是否正确作为指标。这是实际产品评估方法，并不意味着每次辅导后都有一个单独命名的“独立验证”页面。[S3]

### 不沿用旧版分数规则

2026-08 更新的官方帮助页说明，课程掌握百分比按处于 Proficient 或 Mastered 的技能占比计算，巴西和秘鲁除外；当前说明没有列出旧版 50／80／100 点升降阈值。不要把旧文章中的积分阈值写成本项目应复制的当前规则。[S2]

## 对我们项目的适配建议（推断，不是对原生产品的描述）

可借鉴的主线是“以具体任务获取表现 → 困难时就题辅导 → 换一道同技能题独立完成 → 持续更新学习状态”。用户要求的整段播放与播放后初步检查，由本项目保留；Khan Academy 并未证明这个特定入口组合有效。

建议本项目先采用：

```text
保留整段课堂播放
    → 少量代表性问题，保留首次独立回答
    → 根据回答优先处理关键困难
    → 围绕当前任务辅导，记录所用提示
    → 不同的同技能问题，检查独立完成情况
    → 按内容反馈证据和待练习项
```

这是适配路径，不应声称是完整复刻 Khan Academy。我们只有 PPT 和 HTML，缺少其成熟的技能映射、人工题库、提示和标准解答。第一版应先把选定课时的任务、参考解答、提示和课件依据准备可靠，再扩大自动生成范围。仅保存聊天记录也不足以复制其做法，还需要结构化保存题目、学生作答、正误依据和帮助程度。[推断，依据 S3、S4]

## 效果证据的限度

2026 年官方报告称，接入近期作答摘要与先修技能缺口的两项改进，提高了下一题正确率；它们比较的是 Khanmigo 新旧版本。这支持“给辅导器可用的学习记录值得测试”，不能证明 AI 辅导整体优于无 AI，也不能证明长期保持、远迁移，或自动从 PPT 生成题目的有效性。下一题正确率只能作为本项目的即时指标之一。[S3]
