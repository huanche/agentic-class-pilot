# 知识点教学发布说明

## 行为

按 memory/concept/design 的原始目标生成任务，并按学生累计原文逐项更新掌握；评估和教学回复使用不同指令。确认“好，然后呢”不算掌握，切换知识点不重放旧定义，教师追加要求不自动成为评分门槛。课后导航保留真实选中知识点，不伪造掌握。

针对实际已发布 C 语言课的复核，还保留学生“不要重复”的反馈，直到后续实际作答提供新证据；泛泛求助不能清除该反馈或被当作已确定的卡点。反馈保存在原有 assessment_history 中，不改变数据库结构。

教师播放器、视频生成、媒体指针、平台服务及当前线上日志/在线状态功能沿用 main。本次不增加或删除 MP4。

## 验证入口

- `python -m pytest student_agent/backend/tests -q`：真实 PostgreSQL 回归需指定测试专用 `STUDENT_TEST_DATABASE_URL`，只接受 loopback、student_p2_test、postgres。
- `test_release_recovery.py`：候选持久化后跨进程读取；设置 `STUDENT_RELEASE_FALLBACK_ROOT` 可同时测试独立回退构建，涵盖 v3/v4、继续回答、反馈保存和恢复。
- `test_published_course_release_live.py`：默认跳过。显式启用并提供只读导出的课程文件、模型配置文件路径和新的输出目录；使用隔离数据库中的受限 SQL 角色和真实模型，经生产内部身份中间件及 HTTP 命令运行。需在测试环境安装 python-dotenv。导出的教学材料和凭据不提交仓库。
- `test_unresolved_teaching_feedback.py`：先复现反馈丢失导致 explain，再验证跨轮反馈保持 clarify，以及实际作答可解除约束。
- 学生前端：`npm ci`、`npm run test:unit`、`npm run test:e2e`、`npm run build`。
- Linux 临时容器：发布器与备份恢复测试，禁止挂载生产目录或 Docker socket。

已发布一维数组课的 22 场景、22 片段元数据已只读核对；本次真实模型抽样包括提取、四次学生输入、退出、数据库恢复和课后续学，未逐个完成全部知识点，也不代表所有自然语言回复都无重复。真实浏览器视觉/全视频播放不计入这份 HTTP 验收结果。

## 发布与回退

教学会话格式 v4 与当前线上 v3 不具备直接代码回退兼容性。兼容声明包含教学会话读写版本，发布器在活动旧服务存在时拒绝不兼容的常规部署；非法版本声明失败关闭。

首次切换必须维护：预热独立 v4 兼容基线及目标构建，备份并确认恢复路径；保持公网维护，先激活并验证兼容基线，再激活目标。此后目标健康检查失败可自动恢复到基线，不能恢复到不支持 v4 的旧线上代码。基线保留较早的导师执行器和已验证的 v4 状态支持，属于应急降级，教学表现可能回到旧行为。

基线首次激活若失败，保持维护并修复；发布器不会为继续服务而重启不兼容旧写者。候选和回退包、发布器校验值、生产已激活版本必须单独记录。构建完成不等于已激活。
