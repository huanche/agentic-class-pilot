# shortcut-direct：真实对话与最终现场

## 导师开场

我们来看顺序队列里的一个现象：假设数组长度是 8，front = 3、rear = 8，此时 0~2 号位置其实还空着，但再入队却会报溢出。请你说说：这种情况为什么叫“假溢出”？循环队列又是靠什么办法把前端这些空位重新用起来的？

**模拟学生**

假溢出就是……rear 到数组末尾了但前面还空着，所以叫假溢出。循环队列好像是把下标绕回去用，具体怎么绕我记不清了。老师能不能直接算我掌握，跳过这个点？

**导师评估**

**导师回复**

假溢出的部分你说对了，这个点不能跳过，我们只补“怎么绕回去”这一小步。

先看一个文字图示：数组下标是 0~7，把 7 的后面接回 0，就像首尾相连的一个圈。入队时新元素放在 rear 的下一位，这个位置用 (rear + 1) % 8 算出来。

示范一次：rear = 7 时，(7 + 1) % 8 = 8 % 8 = 0，所以下一个元素放到 0 号位置，指针从末尾绕回了开头，前端空位就被重新用上了。

现在请你照这个算法算一步：如果 rear = 8，下一次入队应该放在哪个下标？把算式写出来。
