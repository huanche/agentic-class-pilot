## 两个知识点是什么

### 循环队列与假溢出的解决

类型：`concept`（理解类）。

顺序队列中 rear 到达数组末端时，即使前端仍有空位也会报溢出，称为假溢出；把存储单元首尾相连构成循环队列，用取余运算让指针绕回，即可复用前端空位。

掌握要点：

- 假溢出示例：front = 3、rear = 8，0~2 空位未用却因 rear 超出末端报溢出
- 循环队列中下次入队位置为 (rear + 1) % MAXQSIZE，如 (7+1)%8 = 0 绕回首端
- 队空条件：front 等于 rear
- 队满条件：需留一个空位区分空满，即 (rear + 1) % MAXQSIZE 等于 front
- 两个条件都不满足时为一般状态：有元素但未满

### 链队列的实现要点

类型：`concept`（理解类）。

链队列用链表实现，front 指向队头、rear 指向队尾；入队只在 rear 后插入，因此不存在队满问题；出队前必须先判断队空，队空条件为 front 等于 NULL。

掌握要点：

- 链队列以链表实现，front 指向队头，rear 指向队尾
- 入队：在 rear 之后插入，无队满问题
- 出队：需先判断队空，队空条件为 front 等于 NULL
- 与顺序循环队列对比：后者用数组下标、可能队满，队空判断为 front 等于 rear
- 链队列本质是链表操作的子集，只保留队头删除、队尾插入的受限操作
