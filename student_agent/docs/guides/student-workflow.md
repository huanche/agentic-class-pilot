# 学生学习流程

按 2026-11-22 本地源码整理。

1. 登录平台，加入课程并选择课时。
2. 打开当前课时的已发布播放器。观看时后台可以继续准备共享知识点，准备失败时可重试。知识点准备完成后，视频尚未播完也可确认提前进入教学。
3. 知识点准备完成后进入教学。记忆类可在题卡中分次提交，提交后查看判分和解析，也可在聊天区提问。概念类和设计类在聊天区作答。新建三类型会话首轮每点最多 5 轮，有待巩固的知识点进入最多 8 轮的补强。
4. 知识点目录中的条目定位到已有对话。目录顶部的左右箭头切换当前学习或复习的知识点。跳过课堂知识点会保留未掌握状态。
5. 学习总结后可结束课堂，也可提前结束。结束页提供学习反馈、视频回看和课后继续学习。三类型会话课后补完后进入完成状态，旧版课后流程还可进入自由提问。

退出登录后，重新登录或换设备并选择同一课时，可恢复数据库中的对话、题卡与学习状态。服务会校验课时视频版本。检测到视频变更时会按新版本重新准备课堂，单独的「重置本课学习进度」操作需要页面确认。

旧会话按其保存版本继续，可能保留复述、补强、深入讨论等不同环节。界面阶段与 Agent 教学阶段的区别见[阶段说明](teaching-stages.md)。
