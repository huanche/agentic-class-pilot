# 学生学习流程

更新：2026-11-16，按本地源码整理。

1. 登录平台，加入课程并选择课时。
2. 打开课时播放器。后台准备该发布版本的共享知识点；准备未完成时可先看视频，失败后可重试。
3. 准备完成后进入教学对话。新建三类型知识点会话逐点教学，按学生实际表达评估原始要求；首轮每点最多 5 轮，未掌握点进入最多 8 轮的补强。
4. 完成后总结，学生也可提前结束，反馈记录未完成部分。
5. 在结束页查看反馈、回看视频或继续课后补完。三类型会话补完后进入完成状态；旧版会话另有自由提问阶段。

退出登录不会清空数据库学习记录。重新登录或换设备，选择原课时可恢复历史；已发布内容换版时按新版本校验处理。重置本课学习进度是单独的删除操作，需要页面确认。

旧会话按其保存版本继续，可能保留复述、补强、深入讨论等不同环节。界面阶段与 Agent 教学阶段的区别见[阶段说明](teaching-stages.md)。
