# 学生端 P5：前端学习交互收拢

日期：2026-11-02。接续 [P4](student-p4-implementation.md)，对应[模块架构设计](student-module-architecture-design.md) P5。本次完成前端统一学习交互、结构化求助、暂停和继续，以及本地回归。未部署、未启用正式动态试点；P4 的真实课时/真实模型抽样质量门槛继续保留。

## 1. 交付范围和现有行为

现有默认 legacy 教学流程、原 8/4 轮规则、评分、平台登录与选课、整段播放、提前进入确认、回看、课后对话和重置语义保持不变。P5 未修改后端教学代码、提示词、动作条件或数据库结构。

动态流程仍仅在 P4 的显式课时白名单中新开学习时选择，并固定 flowVersion 和 policy。P5 增加动态页面操作，不将旧会话切换成动态教学，也不默认推广。

## 2. Module 和 Interface

| Module | 职责和 Seam |
|---|---|
| [learning-session.mjs](../frontend/src/integration/learning-session.mjs) | 统一学习交互 Module：入口恢复、课时载入、命令调度、状态刷新、准备轮询、浏览器定位、回看校验和状态投影 |
| [session-commands.mjs](../frontend/src/integration/session-commands.mjs) | 内部可靠命令 Adapter：版本/任务绑定、原载荷重试、回执查询、pending 恢复、同命令在途合并和可取消等待；保留 P2/P3 兼容契约 |
| [session-recovery.mjs](../frontend/src/integration/session-recovery.mjs) | 内部恢复策略：正式身份以服务端历史为准；只有确无历史才允许新开始；演示使用原隔离恢复方式 |
| [session-browser.mjs](../frontend/src/integration/session-browser.mjs) | 内部浏览器 Adapter：课时定位、旧键迁移、签名定位器缓存、重置清理；存储不可用时允许内存中继续学习 |
| [session-http.mjs](../frontend/src/integration/session-http.mjs) | HTTP Adapter：统一编码、错误、命令失败回执及 AbortSignal 传递，可在测试中替换 |
| [StudentApp.js](../frontend/src/components/StudentApp.js) | 订阅 LearningView、展示布局和操作；仅维护草稿、临时发送预览、弹窗、滚动/尺寸与播放器状态，不再直接请求或管理恢复/轮询 |

对页面的主要 Interface：

```text
initialize({url, replaceUrl})       处理平台入口、移除地址栏令牌并恢复或进入目录
loadLesson(lesson)                 查询权威历史；无历史则显示开课入口
dispatch({type, text?, refresh?})   提交学习意图或选择回看/目录等展示
subscribe(listener) -> unsubscribe
getView() -> LearningView
refresh()                         焦点/可见性恢复时复用同一刷新入口
lessonPhase(lessonId)              仅用浏览器定位器显示目录提示
```

学习交互 Module 通过可替换的 HTTP、存储和定时器 Adapter 验证。页面不需要知道命令 ID 如何恢复、如何查询回执或哪个浏览器键保存定位信息。既有命令 Adapter 的测试继续验证其独立的 P2 载荷和回执兼容契约，新场景通过统一 Interface 验证。

## 3. 状态归属和投影

LearningView 组合服务端 SessionView 与前端请求/展示信息：courses、course、lesson、screen、busy、error、connectionError、platformUrl 等。messages、feedback、currentTaskPublic、activityStatus、allowedCommands、phase、stateVersion 和 contentGeneration 均来自权威响应。

screen 只选择目录、开课入口、回看或课后展示。进入回看不修改服务器 done；打开课后活动后仍是 done 下的 after_class 活动。完成轮次、是否可以换题、是否完成独立尝试、是否掌握等均由后端负责，页面没有新增推进规则。

页面保留的学生发送预览不是权威消息，响应到达后由服务端消息替换；失败时移除预览并保留用户原草稿。仅学生手写的回答和问题可从 pendingSubmission 恢复到输入框；按钮生成的求助文字不会被误恢复为学生答案草稿。未提交草稿仍是页面本地状态，不承诺跨设备或刷新后恢复；已经接收的原提交由 P2 命令日志恢复。

## 4. 请求、恢复、轮询与取消

正式恢复继续按 launch_token + lessonId 读取服务器历史，不使用本地签名内容恢复权威教学状态。401/403/409/503 等失败不转换成“没有历史”；只有 404 才允许进入新学习。新平台令牌默认进入目录，避免旧标签页自动定位到另一课时。

正式命令携带 commandId、expectedStateVersion、contentGeneration；回答和结构化求助/提问绑定 currentTaskPublic.taskId。同一意图失败重试沿用原 ID 和原载荷；不同文本或不同任务创建新意图。旧 P2 不含 taskId 的在途回答保持原载荷。重复并发调用同命令共享一次提交和回执查询链。

命令等待保留原有每 500ms 回执查询及次数上限；到达等待上限不判定业务失败。课时交互 Module 每 5 秒刷新当前 video/discussion/done 活动，窗口重新聚焦/变得可见时也走同一刷新入口，接收准备状态、另一设备暂停/继续、结束、撤销或换版。准备轮询和活动刷新共用一条定时循环，重叠刷新共享一次读取；前台请求中不启动额外刷新。

正常状态查询不提交新的学生意图。读到已存在的 pending/processing 命令时，可以沿用原命令身份恢复 P2 的接收/查询协议；failed 命令不会因轮询而自动重试模型。学习或准备的推进仍由原后端执行。已提交但回执丢失时先查询原回执，不把原输入改成新提交；确认服务端已完成后清理旧处理中错误。

切换课时、进入目录或取消最后一个订阅时，取消 fetch、命令轮询等待和刷新定时器，并递增本地请求代次。即使 Adapter 忽略取消，旧请求的结果也不能覆盖新课时或改写浏览器最后定位；同一会话的较低状态版本也不能倒退当前视图。取消前端等待不等于撤销服务器命令，原命令仍保留，后续进入可继续查询。

刷新保持回看/课后展示；若服务器内容代次变化、生命周期变化或课后活动结束，则回到服务器对应的有效视图。相同课时播放数据保持稳定对象引用，避免 5 秒轮询导致播放器反复挂载。播放地址重新获取仍核对课程、课时和课堂绑定，不重启学习。

瞬时连接失败保留现有学习视图并安排后续同步；明确身份失败或撤销引导重新进入，停止当前视图定时刷新。浏览器存储受限时不阻止正式身份进入和命令提交。

## 5. 结构化操作

仅 dynamic_dialogue_v1 显示新增操作，并以最新 allowedCommands 控制可见性和可用性，后端再次验证。legacy 页面不新增教学请求或暂停状态。

| 学生操作 | 命令 | 说明 |
|---|---|---|
| 给个提示 | request_help | 固定求助文字 + 当前 taskId；记录实际策略与帮助 |
| 举个例子 | request_help | 明确请求例子的文字 + 当前 taskId；不冒充学生回答 |
| 提出问题 | ask_question | 发送输入框原问题及当前 taskId；不同于默认回答 |
| 暂停学习 | pause | 不发送答案，不调用教学模型；以服务端响应确认暂停 |
| 继续学习 | resume_activity | 恢复原任务；不重新发题或清空原题 |

暂停后禁用回答输入，显示任务已保留和继续入口；刷新或换设备后读取同一服务端暂停状态。暂停时仍可按原 P4 条件结束课堂；课后视图也使用同一套操作。提示/例子的具体教学内容由 P4 受限执行器生成并记录，本期不新增模型规则或断言其帮助效果。

## 6. 回归结果

后端 **173 项通过**，其中 **51 项真实 PostgreSQL**，88.91 秒。完整保留原流程、P2 并发/恢复、P3 记录/内容版本与 P4 动态事务回归。数据库使用专用回环临时库，未读取正式连接。

前端单测 **42 项通过**，浏览器 **17 项通过**，生产构建成功。Python 编译、七份文档的本地引用/围栏及 git diff --check 通过。临时测试数据库剩余 0，核验数据目录归属后已停止专用测试集群，清理 Next 自动生成的 AGENTS.md。覆盖：

- 统一入口、可信历史恢复、旧浏览器键迁移、无存储可用性和重置只清理本人选中课时定位。
- 结构化提示/例子/问题绑定任务；暂停和继续保持原题；失败求助刷新后保留原命令身份。
- 单一准备/活动刷新循环、重叠读取合并、命令在途合并、取消等待保留提交、迟到课时结果忽略。
- 另一设备暂停、继续或结束后的视图同步；撤销引导重新进入；内容换版退出旧回看。
- 回看地址缺失、失败重试、跨课程地址拒绝、播放器报错回到反馈，刷新不重新挂载相同播放器。
- P2/P3 原回答重试和旧载荷哈希兼容，保留原有 legacy 浏览器回归。

浏览器使用模拟后端；事务和并发另外由真实 PostgreSQL 后端回归证明。本次不验证真实模型教学质量、生产多用户容量或长时间后台标签页的浏览器节流行为。

## 7. 发布和兼容

没有新增迁移或依赖。部署前端需配合已经支持 P4 的后端；新增控制仍仅对服务端 dynamic 会话显示。没有正式令牌或旧版本响应时保留原路由兼容，演示不进入动态流程。

本期是前端收拢和交互接入，不代表已经批准或完成动态教学推广。P4 的白名单继续默认关闭，真实课时/真实模型质量验收按 P4 文档执行。已有 dynamic 会话必须继续由支持该流程和规则版本的后端恢复；不能以不支持动态会话的旧后端覆盖其状态。
