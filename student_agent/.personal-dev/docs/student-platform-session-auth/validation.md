## 本地配置

在专用工作树的 `platform/.env` 中配置独立随机的 `PLATFORM_TO_STUDENT_KEY`，由平台和学生服务共同读取。同一份值用于平台 → 学生的内部调用；原有 `STUDENT_SERVICE_KEY` 继续承担反向调用职责。

`platform/.env`、学生与教师的 `.env.local`、本地进程日志和验证临时文件均被 Git 忽略。已检查内部密钥没有出现在两端前端构建产物或服务日志中。原工作目录的配置未修改。

本地入口为 http://localhost:8088/login，服务只监听回环地址。

## 实际 HTTP 验证覆盖

- 无 Cookie 的浏览器请求被拒绝，公开网关封锁内部服务路径。
- 学生服务拒绝缺失或错误的内部密钥，正确配置可通过调用方认证；不存在的记录仍返回 404。
- 学生实际登录后，可进入课程、加载目录、选择课时；入口不携带课堂启动令牌。
- 缺失 CSRF 校验的写请求被拒绝。
- 视频阶段能通过可靠命令进入讨论，重复请求返回原回执且不重复推进版本。
- 仅将临时测试账号的服务端登录会话设为过期，课堂请求被拒绝；重新登录后从数据库恢复同一条讨论记录及状态版本。
- 退出登录后，后续课堂请求被拒绝。

临时测试账号已停用，其选课与登录会话已清理；测试学习记录保留。没有更改已有用户的登录期限或学习进度。
