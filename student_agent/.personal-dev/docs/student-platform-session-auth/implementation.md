# 学生课堂平台会话鉴权实施记录

初次记录：2026-11-04；后于 2026-11-05 完成生产发布，见 [生产发布记录](production-release-20261105.md)。工作分支 `codex/student-platform-session-auth`，基线为已同步远端 main 的 lzm2（`0b30b39`）。原目录的未提交改动不属于本次工作。

## 已实现的行为

学生浏览器通过平台 Cookie 访问 `/api/session/*`。平台校验服务端登录会话、请求来源/CSRF、当前选课与发布可见性，再携独立内部服务身份调用学生服务。学生服务核对数据库记录归属和课程范围，继续使用原教学规则、状态版本、可靠命令与事务保存。

课程入口返回 `/app?course_id=...`，不返回日常课堂启动令牌。前端不再从旧启动令牌提取身份，不保存课堂令牌，也不为回答附加令牌。旧 URL 最早清理凭据参数；旧缓存只作定位，不恢复正式状态。

登录沿用原 12 小时绝对期限，轮询不续期。401/403 停止操作和轮询；已受理命令继续按原事务完成。重新登录后按原 commandId 查询，丢响应不能变成重复回答或重复重置。账号切换不能加载原账号的消息、草稿或待提交命令。

## 实际模块

| 层 | 实现 |
| --- | --- |
| 平台身份 | `browser_learning_auth.py`：只读取服务端 Cookie、查询到期/账号状态、区分学生课堂与通用登录元数据、绑定当前会话的 CSRF 值 |
| 平台课程权限 | `course_access.get_student_course`：学生必须当前选课，拥有课程本身不能替代选课；管理员保留显式测试权限 |

| 内部传输 | `student_learning_gateway.py`：固定学生服务地址、头部允许清单、独立内部密钥、异步连接池及超时；不转发浏览器 Cookie/Authorization |

| 学生业务 | `main.py`、`session/service.py`、`command_runtime.py`、`infrastructure/commands.py`：正式恢复不依赖旧令牌；命令使用记录固定内容版本；重置墓碑保留回执查询 |

已有 legacy 令牌业务函数保留为离线业务兼容 seam；正式 HTTP 入口统一经过身份边界，不能借此降级。旧教学/事务测试通过独立 business-router seam 保留；新的 Cookie BFF/学生生产 middleware 测试另行运行，不能把前者冒充公网鉴权验证。

同步后的 main 已停止签发未使用的播放授权；本次未改动教师播放器鉴权或重新引入播放令牌，继续依赖现有平台 Cookie 和教师资源权限检查。

## 新配置与发布要求

- `PLATFORM_TO_STUDENT_KEY`：平台和学生服务配置同一个独立随机值，用于平台 → 学生课堂调用；禁止放入前端、URL 或日志。
- `STUDENT_SERVICE_KEY`：沿用学生 → 平台及既有服务接口，不用作浏览器身份。
- `STUDENT_COMMAND_TIMEOUT_SECONDS`：默认 300 秒；BFF 不自动重试写请求，超时返回“原命令结果未知”，随后按编号查询。
- `PLATFORM_AUTH_URL`：学生调用平台应使用回环/私网地址。封锁公网 `/api/v1/internal/*` 前，必须确认既有教师和学生内部调用都已使用内部地址。
- 本地首次配置脚本会生成新密钥；已有配置不会被脚本覆盖，需要在发布环境显式补齐。健康/就绪检查要求内部密钥存在。
- 本次没有数据库结构迁移，不清空历史进度。需要同批部署平台、学生服务、两端前端和网关；先排空或记录已受理命令，再切换。不能单独开启新前端或新路由。
- 回退使用配套的 Cookie/BFF 版本；没有可用兼容候选时保持维护，不退回绕过统一鉴权的接口，不用旧备份覆盖发布后的学习数据。

独立演示必须显式 `STUDENT_DEMO_MODE=true`，有本地演示播放器地址与快照密钥，没有平台内部连接配置，并仅从回环地址访问。它不是正式环境缺少凭据时的回退；正式就绪检查拒绝启用演示播放器。

## 验证证据与限制

本地使用工作树独立 Python 环境和独立回环 PostgreSQL 17，测试账户 `student_p2_test`，测试 fixture 创建/删除各自临时库。没有连接开发业务库或生产库。

验证内容包括：真实命令幂等、重启恢复、跨用户拒绝、重置丢回执恢复、Cookie/CSRF/来源检查、教师退出兼容、数据库故障、旧令牌/旧接口拒绝、仅 GET 准备状态不写入、用户草稿隔离，以及实际平台 app 在 SPA 前挂载新路由。

浏览器用例覆盖原课堂与动态交互、回看、丢响应/模型失败后恢复和新增账号切换草稿隔离。浏览器 API 使用合成响应；平台 BFF → 学生 ASGI 边界和真实数据库命令测试分别验证实际服务边界及事务。

集成契约、跨服务数据所有权、生成客户端一致性、Caddy 配置校验、两套 Node 网关测试和两端生产构建均作为交付检查。
