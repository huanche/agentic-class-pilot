## 配置与切换

- 在生产机生成独立随机的 `PLATFORM_TO_STUDENT_KEY`，保存在 `/etc/agentic-class-pilot/student-learning-auth.env`，root 所有、权限 0600。两套 systemd 服务通过各自 `99-student-learning-auth.conf` 读取同一文件。
- 平台调用学生服务使用 `http://127.0.0.1:8000`；学生调用平台使用 `http://127.0.0.1:8080/api/v1`。原有反向服务密钥保持不变。密钥未进入 Git、前端产物或 CI 镜像。
- 发布器先验证受信的目标环境配置，再用真实受限学生角色执行候选就绪检查，不要求为加载配置而提前切换业务版本。

- 公网课堂 `/api/session/*` 改由平台后端统一鉴权；页面仍由学生服务提供。公网 `/api/internal/*` 和 `/api/v1/internal/*` 返回 404。现有教学、视频和 OnlyOffice 路由保留。
- 公网健康检查使用 `/api/v1/utils/health-check/`；学生就绪检查使用服务器内部 `http://127.0.0.1:8000/api/session/ready`。课堂 API 的匿名 401 是鉴权结果，不能当作服务不健康。
