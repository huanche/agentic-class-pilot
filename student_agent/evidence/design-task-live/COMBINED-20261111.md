## 覆盖

1. 课件中的数组循环示例不被提取为必须照抄的算法。
2. 题目明确指定公式时，提取和首次任务仍保留该条件。
3. 旧课时过细标准：首次给出目标序列而不直接给边界/公式；求助后允许提供必要帮助，解释本身不判掌握；等价正确表达 `i+i+1` 可以通过。
4. 新增组合场景走实际命令 HTTP、实际临时数据库和真实模型：首次出题 → 故意使用 i<=5 并声称 a[5] 合法 → 不掌握 → 结束 → 课后续学 → 连续点击继续 → 提交正确等价解 → 掌握 → 再点击继续。

组合场景核对了续学关联、原题与知识点保留、要求状态不因续学而改变、重复进入不新增消息、全部掌握后不再提问。学生输入为人工设计，不是大模型模拟学生；通过内部平台学习协议进入学生后端，不包含公网登录/Cookie BFF 的再次验收。

## 人工语义复核与残留

- 首次题干明确要求得到 `{1,3,5,7,9}`，未泄露循环边界与计算公式；指定公式反向用例也保留了题设。支持两项修复继续保留。
- 续学没有重问完整原题，也没有要求重做已确认的数组声明或赋值公式；错误并未因为模型讲解而变为掌握。
- **轻度教学冗余仍有残留**：续学会再讲一遍刚讲过的循环边界，并把结果列出来后，再要求学生说明修正后的结果。它围绕真实未掌握内容，没有恢复为整题重考；但不能据此宣布“无效帮助绝不重复”或“绝不要求复述”已彻底解决。
- 建议先作为低优先的帮助质量问题保留。若继续优化，优先让已有 pointConversation 中最近一次帮助决定本轮是否需要重讲；此轮没有据此扩展改造，也没有新增状态或放宽掌握标准。

本轮没有发现需要回退两项修复的功能故障。断言通过仅覆盖本例，词法检查不是通用教学质量证明。
