# 新知识点提问方案：多 agent 真实模型评估

日期：2026-11-10。主 agent 只分工、阅读证据和汇总；全部测试由三个子 agent 执行。采用 Matt `diagnosing-bugs` 的复现闭环和 `codebase-design` 的实际 Interface 测试原则，本轮诊断不修产品。

## 结论

三类型教学的基本掌握判定可用，但逐项学习记录仍混淆“没有证据”和“确实不会”。这会污染缺口与后续反馈，应优先修正。其次是概念验收过分绑定样例、解释重复，以及回复和程序状态不一致。另观察到一次具体教学计算错误，源课程与提取条目自身存在 rear 指针定义冲突，不能全部归因于提问提示词。

## 实际范围

真实归档课程：栈与队列，course `02b49c92-5d63-47bc-9295-2300b7f69203`，lesson `-EXmpqbyvKbisC`。使用现有真实提取结果，没有重新抓取线上课程。三组实际使用其中4个不同知识点（memory 1、concept 1、design 2），覆盖全部3种类型，不等于测遍课程全部11点。

真实教师模型：`deepseek-v4-flash`。学生输入为人工编排的可复现测试答案，不是真人学生，也没有使用另一模型模拟学生。通过当前 `start_discussion` / `classroom_turn` 调用实际教学 Agent、评估工具及逐项状态更新，没有自行重写提示词替代方案。测试是服务内存链路，不是 HTTP、数据库或浏览器端到端验证。

## 已观察到的正常行为

- 完整等价记忆可一次确认多项；片面事实、概念颠倒、只报结论没有被误判整点掌握。
- design接受合法替代实现和部分作答后补全；核心判定6/6符合预期，但不代表逐项状态和教学质量6/6通过。
- 注入指令没有伪造掌握；正确综合回答可以一次确认多项。
- 开场不虚构学生评估，连续第5次输入后进入补强。
- 增量完成全部13次连续不会：recall5/reinforce8后正确进入wrapup，总结未再出题、未声称全部掌握，未确认项仍按未确认描述。课后入口开场及一轮回答可运行，但重新问了最初样例；这不是退出／恢复／持久化验收。

## 建议修复顺序

1. 对评估工具增加证据约束：“未提到／未讨论”不能单独成为需要帮助的依据；保留尚未确认，真正观察到错误再记缺口。回归覆盖同一输入重复调用与未考查项。
2. 对照原课程统一 rear 语义，修正冲突的课程／提取要求，验证写入位置与更新指针的顺序；不能只让模型换一种说法。
3. 明确概念的等价表达验收条件，避免将示例数字当成必要理解证据。
4. 让实际教学回复服从程序动作与现存证据；连续无进展时澄清卡点、换解释，示范范围控制到必要一步。
5. 总结区分已发现缺口、尚未确认和选学建议。
