# 深层探究阶段 — deep_inquiry

**时间位置**：70% - 85% · **默认时长**：7 分钟 · **对应 `host_phase`**：`deep_inquiry`

> **这是全新阶段，旧仓库完全没有对应实现。** 它没有可继承的逻辑，结构与兜底行为都在本文件定义。

---

## 这一幕在干什么

在"记住了"之后追问**更深一层**的四类问题：

| 探究方向 | 问法 | 依据字段 |
| --- | --- | --- |
| **为什么** | 为什么要这样设计？不这样会怎样？ | `KNOWLEDGE-BASE.md` → `为什么这样设计` |
| **如何** | 它是怎么做到这件事的？内部发生了什么？ | `KNOWLEDGE-BASE.md` → `如何实现` |
| **用在哪** | 它能解决什么实际问题？真实场景里哪有？ | `KNOWLEDGE-BASE.md` → `解决什么实际问题` |
| **跨学科** | 它和其他学科/其他章节有什么关联？ | `KNOWLEDGE-BASE.md` → `关联学科` |

---

## ⚠️ 这个阶段能不能跑起来，取决于一件事

**必须给 `rules/KNOWLEDGE-BASE.md` 的 KP 补上那 4 个探究字段。**

这是本阶段唯一的燃料来源。没有这 4 个字段，AI 到 70% 时间点只会干巴巴说"我们深入讨论一下吧"，然后卡住 —— 因为**它不知道往哪个方向深入**。

| 情况 | 结果 |
| --- | --- |
| KP 有 4 个探究字段 | ✅ 探究阶段正常运作，AI 有明确方向 |
| KP 只有 `定义/检测问题/掌握表现` | ⚠️ 降级：AI 只问"能解决什么实际问题"一个方向 |
| 本目录 `questions.md` 也填了 | ✅ 优先用老师写的探究问题 |
| 本目录 `questions.md` 填了 + KP 字段也填了 | ✅✅ 最佳：老师的问题优先，KP 字段作补充 |

## 没配置时的默认行为（保证能跑）

按顺序尝试取问题，取到第一个可用的就用：

1. `stages/deep_inquiry/questions.md` 里老师写的问题
2. 当前段的 KP 在 `KNOWLEDGE-BASE.md` 里的 4 个探究字段（**推荐补上**）
3. 兜底：`"关于 {KP 名}，你觉得它能解决什么实际问题？"`

---

## 推进条件

- `either`（默认）：探究目标证据达标 **或** 7 分钟用完
- 本阶段通常**不产生新星级**，只记录"探究表现"快照（4 星的证据来源）
- 若本阶段被 `lesson-plan.json` 设为 `enabled: false` → 整段跳过

---

## 与其他阶段的关系

```
③ recap_discussion   检验"记住了吗"     → 星级 2-3
④ deep_inquiry       检验"想深了吗"     → 星级 4 + 探究快照
⑤ class_discussion   检验"能交流吗"     → 综合表现快照
```

> ④ 是 ③ 的升级：③ 问"是什么"，④ 问"为什么/如何/用在哪/跨学科"。
