# 探究深度评判标准 — 老师填写

> **老师用**：这里填"探究到什么程度算深、算浅"。
> 当前为空壳。不填时使用通用标准（见文末）。

---

## 填写格式

```md
## 评判维度
- 深度: {是否触到机制/原因，而非停在现象}
- 迁移: {能否连接到新场景或其他知识}
- 论证: {是否有理由支撑，而非只给结论}

## 档次标准

### 深度探究（对应 4 星）
- {具体表现}

### 浅层探究（维持 3 星）
- {具体表现}

### 未进入探究（维持 2 星或更低）
- {具体表现}

## 典型浅答
- {表现} → {说明卡在哪}
```

---

## 关键区别：复述 vs 探究

| | 复述阶段 | 探究阶段 |
| --- | --- | --- |
| 好答案的标准 | **准确、完整** | **有深度、有连接** |
| 背下来算不算好 | 算（3 星） | **不算**（还是要引导往深走） |
| 允许"没有标准答案" | 不允许 | **允许，甚至鼓励** |

> 所以探究阶段的 rubric **不能抄复述的 rubric**。学生答出课本原话，在复述阶段是 3 星，在探究阶段应该继续被追问"那为什么是这样"。

---

## 通用标准（留空时生效）

| 档次 | 判定 |
| --- | --- |
| 4 星 | 能说出机制/原因，能举出课外例子，能与其他知识建立连接 |
| 3 星 | 能说出机制/原因，但只在课本范围内 |
| 2 星 | 只能重复课本结论，说不出"为什么" |
| 1 星 / 0 星 | 无法参与探究，或完全答非所问 |
