# 探究问题 — 老师填写

> **老师用**：这里填"深层探究阶段要问学生什么问题"。
> 当前为空壳。**不填时，AI 改用 `rules/KNOWLEDGE-BASE.md` 里 KP 的 4 个探究字段提问。**

---

## 填写格式

```md
## 探究 1
- 关联: {KP-xxx}
- 方向: {为什么 | 如何 | 用在哪 | 跨学科}
- 问题: {完整的问题原文}
- 期望深度: {什么样的回答算到位}
- 引导路径:
  - 学生没方向 → {怎么给台阶}
  - 学生答得浅 → {怎么往深里追}

## 探究 2
...
```

---

## 四个方向的问法参考

| 方向 | 问题模板 | 什么时候用 |
| --- | --- | --- |
| **为什么** | "为什么要这样设计？如果不这样会怎样？" | 学生已能复述"是什么"之后 |
| **如何** | "它是怎么做到这件事的？中间经历了什么？" | 概念有内部机制时 |
| **用在哪** | "这个知识能解决什么实际问题？" | 想建立"学以致用"的连接 |
| **跨学科** | "它和你学过的其他东西有什么关联？" | 想训练迁移能力 |

---

## 设计要点

1. **探究问题不能有唯一正确答案** —— 否则就是加了难度的检测题，不是探究
2. 每个探究至少要能**追问两层**，否则学生一句就说完了
3. 关联 `KP-xxx` 后，探究表现才能挂到知识点上
4. 问题应指向**理解**而不是**记忆**：问"为什么"而不是"是什么版本"

---

## 示例（参考用，非本课内容）

```md
## 探究 1
- 关联: KP-004
- 方向: 为什么
- 问题: 为什么 SJF 的平均等待时间最短，现实中却很少单独使用它？
- 期望深度: 能同时说出"需要预知运行时间"和"长作业饥饿"两个原因，并说明它们的关系
- 引导路径:
  - 学生没方向 → 问"要按运行时间排序，系统得先知道什么？这个信息好拿吗？"
  - 学生答得浅 → 问"如果所有作业都很长，只有一个短作业不断到达，会发生什么？"

## 探究 2
- 关联: KP-002
- 方向: 用在哪
- 问题: 你去买奶茶排队，店里的叫号系统如果用不同的调度策略，你会有什么体验差别？
- 期望深度: 能把 FCFS / 优先级 / RR 映射到排队场景，并说出各自的公平性取舍
- 引导路径:
  - 学生没方向 → 问"如果你是店长，想让人等得少，你会怎么做？"
  - 学生答得浅 → 问"那如果突然来了一个只买一杯的客人呢？"
```
