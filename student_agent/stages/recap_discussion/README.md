# 复述与讨论阶段 — recap_discussion

**时间位置**：50% - 70% · **默认时长**：9 分钟 · **对应 `host_phase`**：`recap_discussion`

---

## 这一幕在干什么

学生用**自己的话**复述刚学完的内容，AI 识别复述的完整度和准确性，然后**讨论、补充**。

- 学生**主动产出**（复述），不是回答选择题
- AI 对照本轮 segment 的内容和绑定 KP，判断"哪些讲到了、哪些漏了、哪些讲错了"
- AI 通过追问把遗漏的部分补上，而不是直接给答案

## 学生在这一幕的输入形式

| 形式 | 是否必须 | 说明 |
| --- | --- | --- |
| 文字复述 | 是 | 主体形式，学生打字复述 |
| 结构化复述 | 可选 | 按 AI 给的提纲复述（如"先说对象、再说时机"） |
| 语音复述 | 可选 | 后续接入；当前按文字处理 |

## 没配置时的默认行为（保证能跑）

1. **问题来源**：改用 `rules/KNOWLEDGE-BASE.md` 里当前段绑定 KP 的 `检测问题`
2. **开场**："请用你自己的话复述一下刚才这一段讲了什么"
3. **追问**：按学生回答追问 1-2 轮，只补缺口，不给完整答案
4. **判分**：只用 `rules/interaction/MASTERY-STAR-RULES.md` 的通用标准

---

## 推进条件

按 `lesson-data/lesson-plan.json` 里 `recap_discussion.advance_when` 决定：

- `either`（默认）：本幕目标证据达标 **或** 9 分钟用完 → 进入下一幕
- `evidence`：必须证据达标才走

> 这一幕是**抓"理解"证据的主场**。星级 2→3 通常在本幕产生。
