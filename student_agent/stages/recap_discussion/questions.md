# 复述问题 — 老师填写

> **老师用**：这里填"复述阶段要问学生什么问题"。
> 当前为空壳。填了之后，复述阶段会优先用这里的问题；不填则自动用 `rules/KNOWLEDGE-BASE.md` 的 `检测问题`。

---

## 填写格式

```md
## 问题 1
- 关联: {KP-xxx 或 seg-xxx}
- 问题: {完整的问题原文}
- 提问动机: {为什么问这个 / 想听到什么}
- 追问方向:
  - 学生答得不全 → {怎么追}
  - 学生答错 → {怎么追}

## 问题 2
...
```

---

## 设计要点

1. **复述问题必须是开放式**，不能是"是不是""对不对"这类封闭问题
2. 每个问题至少配一个**追问方向**，否则 AI 拿到问题也不知道学生答偏了怎么办
3. 问题应能覆盖当前 segment 的核心内容，而不是挑细节
4. 关联 `KP-xxx` 后，学生的复述表现才能自动挂到知识点上，影响星级

---

## 示例（参考用，非本课内容）

```md
## 问题 1
- 关联: KP-002
- 问题: 外存中的作业变成内存中能上 CPU 的进程，中间经过哪几级调度？谁把作业调进来，谁决定谁上 CPU？
- 提问动机: 检验学生能否把三级调度的对象和时机分开说，而不是笼统说"调度"
- 追问方向:
  - 学生答得不全 → 只问"高级调度调的是作业还是进程？它做完之后作业变成什么？"
  - 学生答错 → 问"作业和进程的区别是什么？哪一个是在内存里的？"

## 问题 2
- 关联: KP-005
- 问题: 一个进程正在 CPU 上运行，这时来了一个运行时间更短的进程。什么情况下系统会打断它？
- 提问动机: 检验学生是否理解"抢占"的触发条件
- 追问方向:
  - 学生答得不全 → 问"非抢占式会怎么做？两者差别在哪？"
  - 学生答错 → 举例引导"如果是时间片轮转，时间片用完会怎样？"
```
