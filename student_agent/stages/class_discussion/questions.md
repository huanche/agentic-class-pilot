# 全班讨论议题 — 老师填写

> **老师用**：这里填"全班讨论阶段要讨论什么"。
> 当前为空壳。**本阶段目前是空壳模式，老师自己主导讨论，AI 不发布议题。**

---

## 填写格式

```md
## 议题 1
- 关联: {KP-xxx / 章节主题}
- 议题: {讨论题目}
- 讨论形式: {自由发言 | 分组 | 辩论 | 案例}
- 期望产出: {讨论结束后学生应该有个什么结论}
- 老师引导点: {老师可以往哪些方向带}

## 议题 2
...
```

---

## 设计要点

1. **讨论议题不能有唯一答案** —— 有唯一答案的应该放在复述或探究阶段
2. 议题应能引出**观点分歧** —— 没有分歧就没有讨论
3. 议题要能让学生**互相回应**，而不只是轮流对老师说话
4. 关联 `KP-xxx` 后，讨论表现可以挂到知识点上

---

## 与探究阶段的区别

| | deep_inquiry | class_discussion |
| --- | --- | --- |
| 参与者 | 学生 ↔ AI | 学生 ↔ 学生（老师主导） |
| 目的 | 想得更深 | 学会交流、表达、回应 |
| AI 角色 | 提问者 | **退居协助** |
| 答案 | 开放，AI 引导 | 开放，老师引导 |

---

## 示例（参考用，非本课内容）

```md
## 议题 1
- 关联: KP-004
- 议题: 如果让你给学校的食堂打饭系统设计一套"调度规则"，你会选哪种算法？为什么？
- 讨论形式: 分组辩论（FCFS 组 vs 优先级组 vs RR 组）
- 期望产出: 各组能说出自己方案的优点，并承认对方指出的缺点
- 老师引导点:
  - 引导关注"公平"与"效率"的取舍
  - 引导追问"如果队伍里有教授和新生，要不要区别对待？"

## 议题 2
- 关联: 章节主题
- 议题: 操作系统的调度策略是"技术决定"还是"价值选择"？
- 讨论形式: 自由发言
- 期望产出: 认识到调度公平性背后有权衡，没有绝对最优
- 老师引导点:
  - 引导把技术问题和现实中的公平问题连接起来
```
