# 全班讨论阶段 — class_discussion

**时间位置**：85% - 100% · **默认时长**：7 分钟 · **对应 `host_phase`**：`class_discussion`

> **这是全新阶段。按当前约定，本阶段 AI 内容为「空壳」** —— 结构完整可调度，但 AI 具体做什么留空。

---

## 这一幕在干什么

**老师主导**的全班讨论，训练学生之间的交流与沟通。学生端 AI 在这一幕**退居协助角色**。

| 角色 | 在做什么 |
| --- | --- |
| 老师 | 主导讨论、点名、串场 |
| 学生 | 互相交流、表达观点、回应同伴 |
| **学生端 AI** | **不主导**。默认只做两件事：提示进入讨论 + 计时 |

---

## 为什么做成空壳

按你的要求：**现在不需要 AI 讨论的内容**，所以本阶段：

- ✅ 在 `lesson-plan.json` 里有完整定义（可开关、有分钟数）
- ✅ `host_phase` 能正常切入 `class_discussion`
- ✅ 编排器能正常调度它、计时、到点切幕
- ⬜ AI 在里面具体做什么 = **留空**

**这不影响整体运作** —— 编排器不会因为这一幕内容为空而卡住（见文末降级行为）。

## 没配置时的默认行为（空壳模式）

1. AI 输出一句：`"进入全班讨论，请老师主导。"`
2. **不做任何提问、不评价、不追问**
3. 按 `lesson-plan.json` 里 `class_discussion.minutes` 计时
4. 到点 → 写入阶段快照 → 进入 `ending`

> 这就是"空壳但不影响运作"的具体含义：**这一幕是透明的**，老师正常上课，编排器正常计时。

## 推进条件

- `budget`（默认）：只看时间，到点就走 —— 因为讨论节奏由老师掌控，AI 无法判定"讨论完了没有"
- 若本阶段 `enabled: false` → 整段跳过（这是当前 `lesson-plan.json` 的默认设置）

---

## 与其他阶段的关系

```
③ recap_discussion   检验"记住了吗"   → 星级 2-3
④ deep_inquiry       检验"想深了吗"   → 星级 4
⑤ class_discussion   检验"能交流吗"   → 综合快照（本阶段）
⑥ ending             总结 + 遗留问题
```

> ⑤ 的产出是**综合表现快照**，不是新星级。它记录"学生在真实交流中的表现"，供老师查看。
