# 全班讨论评判标准 — 老师填写

> **老师用**：这里填"讨论参与得怎么样算好"。
> 当前为空壳。**本阶段目前是空壳模式，AI 不自动评判。**

---

## 填写格式

```md
## 评判维度
- 参与度: {是否主动发言}
- 表达: {观点是否讲清楚}
- 倾听与回应: {是否回应了同伴，而不只是自说自话}
- 深度: {是否触及本质或提出新角度}

## 档次标准

### 优秀
- {具体表现}

### 良好
- {具体表现}

### 待加强
- {具体表现}

## 记录方式
- {讨论表现记为快照，还是折算星级}
```

---

## 设计要点

1. **参与度不等于发言次数** —— 说十句废话不如一次有效的回应
2. **必须包含"回应同伴"这一维度** —— 这是本阶段区别于探究阶段的核心
3. **这类表现通常记为快照，不折算星级** —— 因为这阶段的证据来自人际交流，不适合直接换算成知识点掌握度
4. 如确实要折算星级，说明清楚折算规则（如"优秀折算 4 星"）

---

## 与星级的建议关系

| 建议 | 说明 |
| --- | --- |
| **推荐：记为快照，不折算星级** | 讨论表现写入 `mastery-history.json` 的 `stage_snapshots`，带 `stage: class_discussion` |
| 可选：折算星级 | 只有在老师明确要求时才折算，且最高不超过 4 星（5 星必须来自正式考核） |

---

## 通用标准（留空时生效）

| 档次 | 判定 |
| --- | --- |
| 优秀 | 主动发言 + 观点清晰 + 回应了同伴 + 提出新角度 |
| 良好 | 主动发言 + 观点清晰 |
| 待加强 | 被动发言，或观点与讨论无关联 |
| 未参与 | 全程无发言 |

> **注意**：本阶段默认不产生自动评判。以上标准在老师填写本文件并启用 AI 记录后才会生效。
