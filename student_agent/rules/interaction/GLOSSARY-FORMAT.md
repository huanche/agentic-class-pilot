# GLOSSARY Format

`GLOSSARY.md` 存放这个工作区**已经挣得的精确词汇**。它是学生当前已理解概念的压缩记录，不是一本用来从头学的词典。措辞重要时 AI 可以用这些术语，但学生在对话里用清晰的大白话永远是可以接受的。

路径：`runtime/GLOSSARY.md`

## Template

```md
# {Topic} Glossary

{一到两句话说明这份词汇表覆盖的语言范围。}

## Terms

**{规范术语}**:
{一到两句话定义这个术语是什么。}
_Avoid_: {应避免的别名或模糊说法}

**{另一个规范术语}**:
{定义。}
_Avoid_: {应避免的别名或模糊说法}
```

## Rules

- **只在学生有理解证据时才加词**。被介绍过不算；等到学生能正确使用它再加。
- 每个概念只选一个主张明确的术语，把竞争性说法列为应避免的别名。
- 定义要紧凑。定义这个术语**是什么**。
- 术语一旦建立，就在定义里使用它们。
- 自然形成聚类时，用子标题分组。
- 本工作区特有的含义要显式标注。
- 随着学生理解加深，就地修订定义。不要留下过时条目。
- 本文件在**课程结束时**更新（由 `class-interaction` 在 `ending` 阶段写）。
