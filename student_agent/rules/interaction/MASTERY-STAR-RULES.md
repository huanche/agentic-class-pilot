# 掌握星级规则

本文件定义知识点掌握度的 0-5 星标准。**这是唯一权威规则，任何页面不得另算一套。**

知识点来自 `rules/KNOWLEDGE-BASE.md`。当前掌握状态写入 `runtime/data/mastery-state.json`，每次变化追加到 `mastery-history.json`。

> **2026-09 重构说明**：本版本**已移除"标注"环节**。掌握度不再由学生标记产生，而是由学生在**复述、深层探究、全班讨论**三个阶段中的实际表现，**阶段性记录**。

---

## 核心边界

1. **证据先于评价**。没有真实证据，不产生星级变化。学生说"我懂了"不是证据。
2. **未接触的知识点为 0 星**，前端不绘制星星，只显示"未检测"。
3. **5 星只能由正式考核给出**，其他任何阶段都不得生成。
4. **星级只升不降**（除非考核未通过，此时记录在 `assessment_status`，不改星级）。
5. **阶段性记录**：每个阶段结束写入一条快照，记录"该阶段学生的表现"，与星级变化分开保存。

---

## 星级定义

| 星级 | 状态 | 进入条件 | 前端表现 |
| --- | --- | --- | --- |
| 0 | 未检测 | 知识点存在，但学生没有接触记录 | 不显示星星，显示"未检测" |
| 1 | 已接触 | `guided_learning` 阶段 AI 讲过了该知识点 | 显示 1 星 |
| 2 | 初步理解 | 复述阶段能接住问题、说出零散要点，但需明显提示 | 显示 2 星 |
| 3 | 理解中 | 复述阶段能用自己的话较完整地讲回来 | 显示 3 星 |
| 4 | 接近掌握 | 深层探究阶段能回答"为什么/如何/用在哪"，或能独立解释 | 显示 4 星 |
| 5 | 已掌握 | **通过正式考核**，证据满足 `KNOWLEDGE-BASE.md` 的掌握表现 | 显示 5 星 |

> **1 星的变化（重要）**：旧版本 1 星叫"已标注"，靠学生标记产生。**标注功能已移除**，1 星改名为**"已接触"** —— 含义是"AI 讲过、学生听过，但尚未产生理解证据"。这样星级保持连续，且在无标注的情况下依然可达。

---

## 各阶段如何影响星级

| 阶段 | `host_phase` | 对星级的作用 | 典型跨度 |
| --- | --- | --- | --- |
| 讲解 | `guided_learning` | 讲过即记 **1 星（已接触）**。不讲不记 | 0 → 1 |
| 复述 | `recap_discussion` | 按复述完整度给 **2-3 星** | 1 → 2 → 3 |
| 探究 | `deep_inquiry` | 按探究深度给 **4 星**，并记录探究快照 | 3 → 4 |
| 讨论 | `class_discussion` | **记录综合表现快照，不折算星级** | 星级不变 |
| 考核 | （独立入口） | 唯一可给 **5 星** | 4 → 5 |

**判定原则：**

- 复述阶段：能说出零散要点 → 2 星；能用自己的话完整讲回来 → 3 星
- 探究阶段：能说出机制/原因 → 4 星；只说结论 → 维持 3 星
- 讨论阶段：只记录快照。**讨论表现不折算星级**（除非老师明确要求，且最高 4 星）

## 阶段性记录（快照机制）

**每个阶段结束时**，向 `mastery-history.json` 追加一条阶段快照，记录该阶段学生的整体表现：

```json
{
  "type": "stage_snapshot",
  "snapshot_id": "ss-001",
  "student_id": "student-001",
  "lesson_id": "ch3-process-scheduling",
  "stage": "recap_discussion",
  "stage_elapsed_minutes": 9.2,
  "targets_closed": ["三级调度的对象与时机"],
  "targets_open": ["抢占式与非抢占式"],
  "stars_snapshot": { "KP-001": 2, "KP-002": 3 },
  "evidence": "学生能说出高级调度把作业调入内存，但把中级调度说成'中间那一步'。",
  "occurred_at": "2026-09-17T15:20:00+08:00"
}
```

**为什么用快照：** 老师能看到"学生是怎么一步步变化的" —— 复述时什么样、探究时什么样、讨论时什么样，而不是只看到一个最终分数。

| 字段 | 说明 |
| --- | --- |
| `stage` | 阶段标识，取值同 `host_phase` |
| `stage_elapsed_minutes` | 本阶段实际花了多少分钟 |
| `targets_closed` | 本阶段被证据关闭的目标 |
| `targets_open` | 本阶段结束时仍未关闭的目标 |
| `stars_snapshot` | 本阶段结束时各 KP 的星级快照 |
| `evidence` | 支撑这个快照的学生原话或行为 |

## 星级变化记录

每次星级变化追加一条记录，**不覆盖旧记录**：

```json
{
  "type": "mastery_change",
  "history_id": "mh-001",
  "student_id": "student-001",
  "kp_id": "KP-002",
  "old_stars": 1,
  "new_stars": 3,
  "old_status": "已接触",
  "new_status": "理解中",
  "source": "dialogue",
  "stage": "recap_discussion",
  "evidence": "学生能用自己的话说明三级调度各自的对象与时机。",
  "occurred_at": "2026-09-17T15:20:00+08:00"
}
```

**`source` 允许取值：**

| 值 | 含义 |
| --- | --- |
| `dialogue` | 来自对话表现（复述/探究阶段） |
| `assessment` | 来自正式考核（唯一可产生 5 星） |
| `manual` | 老师手动调整 |

> **已移除**：`class_point`（标注来源），因为标注功能已删除。

**`stage` 字段**：记录这次变化发生在哪个阶段，便于追溯。

## 当前状态字段

`mastery-state.json` 中每个知识点使用以下字段：

```json
{
  "kp_id": "KP-002",
  "stars": 3,
  "status": "理解中",
  "assessment_status": "未考核",
  "last_source": "dialogue",
  "last_stage": "recap_discussion",
  "last_evidence": "学生能用自己的话说明三级调度各自的对象与时机。",
  "updated_at": "2026-09-17T15:20:00+08:00"
}
```

**`assessment_status` 只允许：** `未考核` / `考核中` / `已通过`

> **已移除字段**：`annotation_ids` / `last_annotation_id`（标注功能已删除）
