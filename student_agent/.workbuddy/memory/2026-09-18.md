## 编排器时钟方案落地（方案 B：真实时钟）

用户确认采用**方案 B（真实时钟）**，废弃原"LLM 估算每轮耗时"思路。

### 核心设计
- **时钟是输入不是环境**：`now` 字段由会话层注入 state，图内节点一律不调 `datetime.now()`。
  这样图是纯函数 —— 可单测、可回放（喂一串时间戳就能重放整节课）。
- **新增 `tick` 节点**（9 → 10 个节点）：所有时间计算集中在此，其他节点只读结果。
  在此之前"到底按哪个数算耗时"会散落在多个节点里，改不动也测不了。
- **净时长 vs 墙钟时长双口径**：
  - `stage_teach_minutes` / `lesson_teach_minutes` = 扣除挂机后的有效课时，**切幕只看这个**
  - `stage_elapsed_minutes` / `lesson_elapsed_minutes` = 真实流逝时间，给老师复盘
- **挂机治理三级**（`clock_policy`）：
  - `idle_gap_minutes=8`：单轮间隔超 8 分 → 只按 25% 记课时
  - `absence_grace_minutes=15`：超 15 分 → `absence_kind=absent`，记 0
  - `absent_policy`：`extend` 冻结预算 / `skip` 跳过本幕 / `end` 提前结束
- **缺席判定只看 `now - last_activity_at`，不看本幕开了多久** ← 这是踩过的坑，见下

### 踩坑与修复（重要，回归测试抓出来的）
`clock_reference.py` 12 条回归测试中发现一个真实设计缺陷：

最初写法是"单轮间隔超宽限 **且** 本幕墙钟超宽限 → 判缺席"。
后果：一幕一旦超过 15 分钟，即使学生**刚在 4 分钟前说过话**，也会被永久判为缺席，
→ 预算永远冻结 → **这节课下不来**。

修复：缺席判定只依据 `now - last_activity_at`（"上一轮距今多久"），
与幕的总墙钟时长彻底解耦。`absence_grace_minutes` 的语义从"幕开了多久"
纠正为"上一轮隔了多久"。

教训：**不要把"这一轮间隔长"和"整幕都没人"混为一谈。**

## 实测接真模型：发现并修复"teach 单层"架构缺陷（用户要"实测 langgraph 怎么接 AI"）

用户提供 DeepSeek Key（`AGENT_LLM_BASE_URL=https://api.deepseek.com/v1`，model `deepseek-chat`），
配进 `.env.local`（已 gitignore）。

### ★ 核心缺陷：原 `teach` 接上 LLM 会把编排架空

原写法是"有 LLM 就调模型，调完直接 `return`"。后果：
- 讲解阶段不推进 `active_segment_id` → 段落永远停在第一段
- 复述/探究不挂起 `pending_question`、不推进 `q_index`、不设 `current_target`
  → `judge_mastery` 拿不到目标 → 星级不涨、目标永不开 → 只能靠预算切幕
- **一句话：接上 AI 后课变成了自由聊天，编排器失效。**

修复：把 `teach` 拆成**两层**（已写进 `ORCHESTRATOR.md` 第 3.1 节）：
```
第一层  确定性骨架（永远执行）→ 决定讲哪段/问哪题/给什么反馈，产出 directive
第二层  LLM 润色（可选）      → 只把 directive 变成自然语言；失败用朴素文案
```
**铁律：模型不决定讲什么、问什么，只决定怎么措辞。**

### 由此得到的三条约束（都是实测踩出来的）
1. **directive 必须带内容锚点**。曾只写"往深讲一层"，模型在无范围约束下
   编出了本课没有的"马尔可夫性质、参数估计"（本课是处理机调度）——幻觉。
   修：同段续讲时锚到段落 content；收尾时列出全部段落标题并显式禁止新内容。
2. **传给模型的文案不能有 KP 编号**。模型会照着念，学生听到"KP-004"没意义。
   修：加 `kp_title()`（从 `## KP-001 调度是什么` 解析），探究题与下课总结改用中文标题。
3. **收尾轮 directive 要显式写"不要再提新问题"**，否则模型继续往外扩。

### 最终验证（最有说服力的一条）
有 / 无 LLM 两种模式跑同一串时间戳，**剔除老师说的话之后 51 行编排结果逐行相同**
（切幕时机、证据、星级、阶段快照完全一致）。这证明"模型不参与编排"不是说法，是被验证的事实。

补充：接 LLM 后**不再逐字节可回放**（模型输出不确定）——可回放性只在降级模式下成立，
本质上仍是因为时钟注入，与逐字回放是两件事，别混为一谈。
