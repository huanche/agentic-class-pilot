# 核心知识点提取改造
采用 Matt codebase-design：通过提取模块 Interface 隐藏校验、修复、去重和身份生成，调用方不重复处理。

需求：程序传入课程名称；每课时 1–3 个知识点；模型仅输出 name/explanation；接入后续提问；保留旧会话兼容。

方案：
1. 新工具协议与提示词，旧三类型协议仅供历史内容读取。
2. 提取结果保留 name/explanation，程序派生 title/content/description 兼容现有界面与无类型提问流程。
3. 内容协议新增 v3；历史 v1/v2 继续校验。提取器升级触发新缓存，旧会话仍固定原内容。
4. 平台读取 Course.title，经发布请求传入，存储在队列 coverage 元数据中；直接准备从 context.courseTitle 传入。
5. 测试结构修复、数量约束、课程名传入、内容存储和后续对话；执行后端回归、前端测试构建及真实模型提取；打包输入、输出和验证记录。

不部署线上，不改现有学生进度。无实质文本在模型调用前拦截；缺少课程名不能伪造课程名。
