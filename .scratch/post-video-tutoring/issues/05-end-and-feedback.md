# 05: 明确结束与课后反馈

**What to build:** 辅导阶段的唯一出口是"明确结束"：学生主动说结束，或计划时间到后 AI 询问、学生确认结束。明确结束后生成完整反馈并入库：多版本保留（每次明确结束一版）、默认展示最新、预留教师视角摘要字段（本次不做教师端页面）。反馈内容栏目结构由实施者起草（含：各知识点终值星级与证据摘要、复习用时、作答统计、后续建议），在工单评论中标注"待用户过目"。辅导阶段内不出现返回课堂、重看视频、跳转其他课时的按钮。结束后学生落到课后页，课后页展示最新完整反馈；课程列表中全部课时完成的课程卡出现"查看课程反馈"轻量入口，点进去是各课时反馈列表。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 明确结束（学生主动 / AI 到点询问后确认）→ 生成反馈入库；同一次结束不重复入库（幂等）
- [ ] 平台 alembic 迁移：after_class_reports 支持多版本 + 教师视角摘要字段；demo 态 JSON 同步支持多版本

- [ ] 辅导阶段 UI 无其他出口按钮（唯一出口=明确结束）
- [ ] 结束后落课后页，展示最新反馈完整内容
- [ ] 课程卡轻量入口：全部课时完成才出现，列出各课时反馈（读最新版）
