# 07: 模型翻译官——自然语言意愿识别

**What to build:** 正则没认出的复习意愿（顺序/自评/时长），让模型把学生的话**翻译成一行结构化 JSON**（order / self_ratings / duration_minutes），骨架**校验**（编号在目录内、星级 1–5、时长 1–240 分钟）后才写状态；不合法字段直接丢弃。正则认出的字段优先，模型只补缺口；模型缺席或翻译失败，行为退回纯正则（现状）。**结束意愿不交给模型触发**（仍走正则 + 结束确认回合），防止误杀。

## Comments

### 2026-10-21 Claude（工单 07 实施）

**做了什么**

- `_tutoring_extract_intent_llm`（模型翻译官）：正则没认全时，把学生的话 + 知识点目录交给模型，翻成一行 JSON（order / self_ratings / duration_minutes，没表达的字段不输出）。system 提示词里写明「只列他点到的，没点到的不要编」。
- `_validated_tutoring_intent`（骨架校验，fail closed）：编号必须在目录内、星级 1–5、时长 1–240 分钟、类型必须对——越界字段直接丢弃，整段不合法就当学生没说。
- 接线（teach 的 tutoring 分支，正则解析之后）：`llm_available` 且（顺序/自评/时长）有缺口才调翻译官；**正则认出的字段优先，模型只补缺口**；模型补出顺序时当前聚焦知识点跟着走。结束意愿**不**交给模型触发——仍走正则 + 既有结束确认回合，防误杀。
- 模型缺席/翻译失败 → 行为与之前完全一致（纯正则）。

**测试**

- 新增 4 用例：自然说法「第二个留到最后看吧」→ order 生效且润色指令带确认；「给我一刻钟」→ 15 分钟重设；越界值全丢弃状态不动；正则与模型冲突时正则优先。连同 api_integration 共 52 过（1 个既有平台态 skip）。
- 既有 mock 判答/出题的用例不受抽取调用串扰（按 system 关键词「意图解析器」分发隔离；非法 JSON 自然落空）。

**设计边界（重要）**

- 模型是**翻译官不是决策者**：它只能翻结构化意图，写不写状态由骨架校验说了算；改状态的确定性、可测性、可降级性一点没丢。
- 别把「结束」加进模型可翻的字段——下课是高危动作，误杀一个想继续的学生比漏掉一句结束短语代价大。
